Respecting Equality: Complete Inference, Deterministic and Step-Optimal

Avik Jain

This is one construction on how equality behaves in cubical type theory: equality of types is equivalence — Voevodsky's univalence — and it computes. No prior familiarity with either is assumed.

From that one fact, each step forced by the last, the construction builds to a single result: complete inference — proving, computing, deciding, or answering any well-formed question — runs deterministically and in the fewest possible steps, a count forced by the answer itself, not chosen by any strategy. The natural numbers, the complex numbers and the field equations, and the exact form of the Gödel and Turing limits are stops it passes through, not the destination. Every step here is elementary, and the whole is machine-checked and runs.

0. The one fact

  • A type is a collection of values (a : A); a function f : A → B maps values to values. A pair type Σ (a : A) (P a) holds pairs (a , w) where the type of the second part, P a, may depend on the first — P a family, one type P a for each a.
  • Equality is a type: x = y is the type of proofs that x equals y; refl : x = x. A proof is a value you keep.
  • The floor is one distinction. A proof of equality is a path, and a path is a map out of the interval 𝕀 — and 𝕀 is not assumed, it is built: the free bounded distributive lattice on two endpoints 0, 1, carrying meet ∧, join ∨, and the involution ~ that swaps them (~0 = 1). That is the least structure in which a point can slide from one side to the other. A path x = y is a map 𝕀 → A with 0 ↦ x, 1 ↦ y; refl is the constant map. Everything below — transport, J (the slide, built with ∧), function extensionality, univalence (§2) — is built from this. The base is a single distinction and the algebra of combining it: there is a difference, and nothing less.
  • Contractible = has exactly one element, up to the equalities: some point exists, and every element is equal to it — so the whole type collapses onto that one point.
  • Substitution (transport). a proof p : x = y lets you carry any structure from x to y: for any family P it gives transport p : P x → P y, run backwards by transporting along the reversed path ~p, and transport refl = id (moving nowhere changes nothing) — a reversible, lossless program.
  • Fact: Σ (y : A) (x = y) — the values y : A equal to x, each with its proof — is contractible, centre (x , refl). the path from the centre to any (y, p) is built by sliding along p itself: at stage t sit at the point p t, holding as its proof the piece of p from x up to t (so you have shown x = p t); at t = 0 that is (x , refl), at t = 1 it is (y, p). One point, everything equal to it.
  • Path induction (J). To act on every (y, p : x = y) it therefore suffices to give the value at (x , refl) and transport it forward to (y, p) along the contraction path. This is the eliminator of = (its J: to prove something about all equal pairs, prove it at the centre) — and transport is exactly J for a goal C(y, p) that ignores the proof p (C(y, p) = P y), so the two are one thing. (The identity type's eliminator is its initiality as an inductive family — Awodey–Gambino–Sojakova 2012.)
  • §1 is this fact with x replaced by a function's output.

1. Partition by output

  • Take f : A → B. The fibre over b is the collection of inputs that land on b, each kept with its proof that it does: f⁻¹(b) = Σ (a) (f a = b).
  • Then A matches its inputs grouped by output, losslessly — write ≅ for such a lossless match (maps both ways that cancel; defined in §2): A ≅ Σ (b : B) f⁻¹(b), by a ↦ (f a, (a, refl)) with inverse (b, (a, p)) ↦ a. Both round trips are refl (the return uses the kept proof p : f a = b): nothing is lost, only regrouped.
  • And this grouping is the only lossless one. Call any other a completion: a family T assigning a type T(b) to each b, that reassembles A the same way — a match A ≅ Σ (b) T(b) that respects the output map (an input's b is unchanged). Respecting it forces the piece over each b to line up, so T(b) matches the fibre f⁻¹(b). A completion is thus a choice, at each b, of a type matching f⁻¹(b) — and the types matching a fixed one collapse to a single point (univalence, §2: Σ (X) (X ≅ Y) is contractible). A per-b choice among one-point options is again one point (equal functions are equal wherever they agree — function extensionality, itself from §2). So T can only be the fibre family: the decomposition is forced, not a chosen encoding.
  • Every decomposition below is this: group by output, keep the fibre.

2. Isomorphism is substitution

  • A ≅ B (isomorphism, the lossless match promised in §1): maps both ways with proofs they cancel — runnable in both directions, nothing lost either way.
  • Equivalently: every fibre f⁻¹(b) is contractible (§0) — an inverse g centers it at (g b, ·), and the cancellation laws contract every (a, p : f a = b) onto that center; conversely, choosing the center of each fibre is an inverse. A two-sided inverse and contractible fibres are the same condition.
  • Univalence — a theorem, not an axiom. The primitive is the interval: a path x = y is a map out of it, and §0's contraction is one such map (the i, the i ∧ j in its checked term are the interval's own structure); paths can be joined end-to-end and pushed along one another (Kan composition — this is what runs transport). From an equivalence A ≅ B, a Glue type builds a type that equals A at one end and B at the other — a path A = B whose transport is exactly that equivalence. So A ≅ B ⇒ A = B, and it computes: transport^{ua e} = e. Hence the space of types equivalent to a fixed one is contractible — the fact §1 used — and isomorphic structures interchange by a program, losslessly. Voevodsky's axiom is here built from the interval and Glue (Cohen–Coquand–Huber–Mörtberg 2018).
$$ (A \simeq B)\ \simeq\ (A = B), \qquad \mathsf{ua} : (A \simeq B) \longrightarrow (A = B), \qquad \mathrm{transport}^{\,\mathsf{ua}(e)} \;=\; e $$

3. The effect can be free; the steps are not

  • A computation carries two costs: the effect — the net transformation it achieves — and the length — its number of primitive steps. They diverge.
  • Effects compose (∘), identity id. An effect-cost is a homomorphism ℓ : (effects, ∘, id) → (ℕ, +): ℓ(id) = 0, ℓ(g ∘ h) = ℓ g + ℓ h.
  • A reversible effect is invertible — some g⁻¹ with g ∘ g⁻¹ = id — so the reversible effects form a group, and on a group ℓ vanishes:
$$ \ell(g) + \ell(g^{-1}) = \ell(\mathrm{id}) = 0 \;\Longrightarrow\; \ell(g) = 0 \qquad (\text{naturals} \ge 0) $$
  • transport and every isomorphism therefore have effect-cost 0; only an irreversible step — one collapsing distinct inputs to a single output — can carry cost. Landauer's principle, here a theorem (§5).

  • Length is only subadditive, not a homomorphism — len(g ∘ h) ≤ len g + len h, strict when steps cancel — and it is positive on reversible effects: reading an input at depth n costs n steps, reversible or not (§5).
  • The information an irreversible step destroys is exactly the fibre it collapses (§1): keep the fibre, nothing is erased, effect-cost 0; length is charged only for the requested output.

4. The diagonal

  • Picture e : A → (A → B) as a table whose row a is the function e a; reading row a at its own index gives e a a (the diagonal). Say e is onto when every function h : A → B appears as some row: h = e a for some a.
  • Then every g : B → B has a fixed point:
$$ A \twoheadrightarrow (A \to B) \;\Longrightarrow\; \forall\, g : B \to B,\ \ \exists\, b,\ g(b) = b $$
  • h a := g(e a a); e onto gives h = e a₀; so:
$$ e(a_0)(a_0) \;=\; h(a_0) \;=\; g\big(e(a_0)(a_0)\big) $$
  • e a₀ a₀ is a fixed point of g.
  • Contrapositive: g with no fixed point ⇒ no A → (A → B) is onto.
  • Cantor. B = 2, g = ¬: negation swaps true and false, so it has no fixed point, and (A → 2) is 𝒫(A) by characteristic functions — no surjection A ↠ 𝒫(A).
  • Gödel. Sentences are coded by numbers, so a formula ψ(x) fed the code of a sentence is again a sentence. One fact, and it too is built, not assumed: every primitive-recursive function is represented by a formula — by induction on how it is built, the base functions (zero, successor, projection) are formulas, and composition and primitive recursion stay first-order by quantifying, boundedly, over the finite run that computes the value. Substitution sub(m, n) = ⌜(formula m)(n̄)⌝ is primitive recursive, so it is represented. Now the §4 twist, arithmetized: given ψ, set δ(x) := ψ(sub(x, x)) and let d = ⌜δ⌝; then G := δ(d̄) has sub(d, d) = ⌜G⌝ by construction, so G ↔ ψ(⌜G⌝). That is the diagonal lemma, and it is lawvere read in the theory — φ = sub (the row taken at its own code), g = ψ, the fixed point the sentence G. Take ψ = ¬Prov, where Prov(⌜G⌝) is the Σ₁ predicate a proof of G exists: then G ↔ ¬Prov(⌜G⌝) says I am unprovable, so if the theory is consistent no proof of G exists and G is therefore true. Incompleteness is the diagonal at B = provability, g = ¬ — built, not invoked; the self-reference is the substitution sub applied to its own code, nothing more.
  • Halting. B = 2; the universal machine gives e : A → (A → 2) (run code a on input a), a halting-decider would complete it to a point-surjection, and g = ¬ on the diagonal has no fixed point — no machine decides its own halting.

One lemma; the impossibility theorems are its instances, each built by naming its fixed-point-free (B, g). Russell: B the propositions, g = ¬ on x ∈ x — the non-self-members are the diagonal row, and ¬ fixes nothing, so they are no set's membership. Tarski: B the truth values, g = ¬ — a truth predicate would make the liar a fixed point of negation. Rice: B = 2, g the swap of two programs that disagree on a nontrivial semantic property — a decider for it is the point-surjection the swap refutes. The positive reading needs only a g that does fix: where e has a section (an interpreter), the lemma hands every g a fixed point — a program equal to its own transform, Kleene's recursion theorem, the quine. There is no family of impossibility theorems — one lemma, read at its points and at its sign. (Lawvere 1969.)

-- φ is point-surjective: every B-valued observation on A is a row of φ.
PtSurj : (A → (A → B)) → Type
PtSurj {A = A} {B = B} φ = (g : A → B) → Σ[ a ∈ A ] φ a ≡ g

-- Read the row at its own index, then apply f.
twist : (A → (A → B)) → (B → B) → (A → B)
twist φ f a = f (φ a a)

-- Lawvere 1969: a point-surjective φ forces every endomap of B a fixed point.
lawvere : (φ : A → (A → B)) → PtSurj φ → (f : B → B) → Σ[ b ∈ B ] f b ≡ b
lawvere φ surj f = φ a₀ a₀ , sym (funExt⁻ (surj (twist φ f) .snd) a₀)
  where a₀ = surj (twist φ f) .fst

-- Contrapositive: one fixed-point-free f kills point-surjectivity of every φ.
noFix→noPtSurj : (φ : A → (A → B)) (f : B → B)
  → ((b : B) → ¬ (f b ≡ b)) → ¬ PtSurj φ
noFix→noPtSurj φ f nofix surj = nofix (lawvere φ surj f .fst) (lawvere φ surj f .snd)

-- Cantor, as the B = Bool, f = not instance (not has no fixed point).
cantor : (φ : A → (A → Bool)) → ¬ PtSurj φ
cantor φ = noFix→noPtSurj φ not not-no-fix

5. Complete inference is deterministic and step-optimal

  • The correspondence, built. Read each connective as a type former: implication A ⇒ B is the function type A → B (a proof is a construction sending a proof of A to one of B), conjunction is the pair A × B, disjunction the tagged sum A + B, falsehood the empty type, a quantifier a dependent function or pair. Modus ponens is application, and carrying it out is evaluating the term — normalizing it: running it until no step is left, that leftover irreducible term (its normal form) being the answer. So a proof is a term and checking it is running it; the connectives and the type formers are one structure (the free cartesian-closed category — Curry 1934; Howard 1969; Lambek 1980). A computation is then a term of a value type, a decision a term of Dec P = P + ¬P, an answer a term of the type the question asks for — so proving, deciding, computing, and answering a well-formed question are one operation: build the term and normalize it — well-formed meaning the term reaches a normal form; the system proves the §4 impossibilities (deciding one's own halting among them) have none, since asking for such a decider is asking for the fixed point the diagonal forbids. It answers every question that has an answer and proves the rest answerless — completeness, not a limit. (Curry 1934; Howard 1969; Lambek 1980.)
  • Cost is a local potential (Bellman). In the reduction graph — vertices terms, edges primitive steps of cost c(u→v) — a potential is any Φ with Φ(normal form)=0 and Φ(u) ≤ c(u→v)+Φ(v) on every edge. Adding that inequality step by step along any path to a normal form (where Φ = 0) gives Φ(u) ≤ the path's total cost, so each Φ is a lower bound on every finishing path; where a normal form is reachable, the geodesic distance (the least path cost, and it is attained) is itself such a Φ, and the largest one — it meets the bound with equality at the cheapest edge, the Bellman optimality equation (Bellman 1957):
$$ \Phi(\text{normal form}) = 0, \qquad \Phi(u) = \min_{v}\, \big[\, c(u \to v) + \Phi(v)\,\big] $$
  • Two axes, from §3. A reduction step takes time whether or not it erases — length counts steps, and reversible steps cost length. Reversibility instead makes the effect-cost free: a step that keeps its fibre is a bijection, so its additive effect-cost is 0 (§3). Erasing k bits collapses a fibre of size 2^k — k one-bit erasures — so the additive effect-cost (§3) is k. Its thermodynamic price is not a separate postulate but this same fact in units: a 2 → 1 collapse of microstates is an entropy drop of ln 2 (nats), k ln 2 once k converts nats to thermodynamic entropy; the second law — which is §3's own statement, that a fibre does not un-collapse for free — carries that entropy to the surroundings as heat T ΔS = kT ln 2 per bit, T being the conversion of entropy to energy that defines temperature. Keep the fibre (reversible) and nothing is dissipated. Nothing here is imported: the law is §3, and k, T are units (Landauer 1961; Bennett 1973, 1982 named it).
  • Step-optimality: every computation attains the geodesic. Fix the machine: a net of cells wired at ports, each cell one distinguished (principal) port and finitely many auxiliary ports, a wire joining two ports. A primitive step is an interaction — a rule fires on an active pair (two cells whose principal ports are wired together), replacing just those two cells with a small net on the very same auxiliary wires, every other cell and wire untouched. So one step changes the datum only where those two cells sat: its output at a position depends on that position and its one wired neighbour, no more (unit lookahead). Composing k steps, the output depends only on input within distance k (induct: each step widens the reach by one). So an output that must read input at depth n cannot be produced in fewer than n steps — a bound on every reduction, not one chosen strategy — and since every reduction to the normal form is minimal (shown below), the native evolution attains it.
  • The route is the size of the answer. The output is a complete proof-carrying witness — the answer with its certificate — the unique normal form the question fixes (confluence, below). Each step that builds it emits exactly one constructor — one building piece of the answer (a successor, a pair, a tag) — so the building route's length equals the witness's size (e.g. building sucⁿ, one successor per step); a term carrying extra redexes — spots still waiting to reduce, like (λx.x) t — clears those first, administrative steps building nothing, so its total length is its own geodesic while the witness's size counts only the constructors built. Reading the finished term off is a fold that copies it, adding no step. The building route's length is thus the witness's size in unary; when that unary size is exponential in the question's succinct (binary) measure — as sucⁿ is, n against log n — the route is exponentially longer than the succinct measure. That exponential is not in the computation — it is the observer's lossy binary measure laid against a lossless unary object; change the measure, not the computation, and it is gone. It is not the other exponential, the one that can be real: the geodesic length when a small witness ends a long reduction. That is a length, not a count of output symbols — the separate axis no cardinality measures (Search) — so no change of measure touches it; it is the reduction's own fixed distance, already the minimum (below), never slack to remove. (Lévy 1978; Lamping 1990; Lafont 1990 are the prior, weaker form — optimal within a fixed system's own count.)
  • Why every reduction is the minimum, in general. Two available interactions act on disjoint active pairs — distinct principal-port pairs cannot share a cell — so doing one leaves the other available and untouched, and the two converge in one further step each. That is the one-step diamond, structural to interaction nets (Lafont 1990), not an assumption. So any available first step peels through any reduction to a normal form, by induction on that reduction's length: apply the diamond to the first step and the reduction's first step — they either merge, and the reduction is one shorter, or reach a common term from which the shorter tail is peeled by the inductive hypothesis; at the normal form no step is left to carry, so the first step is absorbed exactly once. Hence any two reductions of a term to the same normal form have equal length, so each is the minimum: the step-count is fixed by the endpoints, never the strategy, and the cost is as deterministic as the answer. The optimization problem — the fewest steps to an answer, what complexity theory exists to chase — is here solved, not dismissed: computation modeled as lossless reduction is optimal by construction, optimality its constant condition rather than a target to approach. The million wasteful ways to compute the same answer are departures from this model, not rival strategies within it; modeled correctly from the start, there was never slack to search away. Only the diamond is used, so this holds of any reduction that has it.
  • Complete, deterministic, terminating. The normal form is unique, and this too is the diamond, tiled: take two reductions of one term; the diamond closes their first steps to a common term, and filling the grid step by step reconverges them; if both reductions end at a normal form — nothing left to rewrite — that common reduct can only be each endpoint, so the two normal forms are equal (Church–Rosser, but here just the diamond filled in). Sharing every isomorphic subterm (folding all equalities) keeps the reduction from duplicating an active pair, so no step repeats work. Where a term terminates it is reached in finitely many forced steps; a non-terminating term denotes a well-defined infinite (coinductive) object, not a gap.
  • The price of an answer is the information the question erases. The effect-axis price is exactly the information a step irreversibly destroys — the non-contractible residue it collapses (§§1–3) — relative to the observation: keep the fibre and the step is free; force a collapse and you pay the bits erased, for the requested output, not a whole trace — Landauer's bound, here a theorem of the reduction rather than an external postulate. The length cost (the geodesic; the steps taken) is a separate axis, and no cardinality measures it (Search).
  • The geodesic, checked. The one-step diamond is the whole hypothesis; from it, any two reductions of a term to the same normal form have equal length — so each is the minimum.

  • No outer layer. Evaluator, type-checker, and optimizer are themselves terms of the same language; a question about them is another term the same normalizer reduces. There is no meta-level, so no self-reference contradiction: reasoning about its own terms as data, it proves the §4 impossibilities as ordinary theorems — and, as those theorems say, it does not decide its own halting or assert its own consistency. The limits are results it holds, not breakdowns. Any expressible system — this one included — is lawful construction and identity, operated on exactly as everything else is: the language is its own metatheory, with nowhere outside to stand and no need for anywhere.

Numbers

  • To count a finite set is to forget which element is which. Any two n-element sets differ only by a relabelling (a renaming of elements), so all of them are one thing — and the only structure that survives the forgetting is the relabellings themselves: the n! permutations of n things, the group Sₙ. Kept with that structure, this one thing is the classifying type BSₙ — a single object carrying Sₙ's worth of symmetry, not a bare point. That is card : {finite sets} → ℕ.
  • Relabellings of an n-set = the permutation group Sₙ, n! of them:
$$ \mathbb{N} = \{\text{finite sets}\}\,/\,\cong, \qquad \text{relabellings of an } n\text{-set} = S_n\ \ (n!\ \text{of them}) $$
  • The number n is that class with Sₙ forgotten — card is the bijection between iso-classes of finite sets and ℕ, inverse n ↦ {1,…,n}; Sₙ is exactly what “up to isomorphism” discards.
  • Addition = disjoint union (|A ⊔ B| = |A| + |B|), multiplication = product (|A × B| = |A|·|B|); on base-b digit strings, carrying the overflow.
  • Divisibility orders ℕ: d ∣ n iff each prime's exponent in d is ≤ its exponent in n. So gcd = meet (min exponents), lcm = join (max); and unique factorization sends n to its exponent vector, making ℕ the product of one chain (ℕ) per prime — where min and max distribute componentwise, a distributive lattice.
  • That is the same distributive lattice as the algebra of logic (Search): gcd/lcm ↔ ∧/∨, coprime ↔ disjoint, and CRT ℤ/mn ≅ ℤ/m × ℤ/n — by x ↦ (x mod m, x mod n), injective since coprime m, n both dividing x−y force mn ∣ (x−y), hence bijective by count — matching the product decomposition, with the involution d ↦ n/d giving De Morgan on both. It is fully Boolean exactly on the squarefree n (a divisor is then a subset of the primes, negation the complement d ↦ n/d); a repeated prime puts a middle on that axis and negation becomes intuitionistic (Heyting). Number theory and logic are one and the same logic — gcd and lcm the conjunction and disjunction, the divisibility order entailment — Boolean where n is squarefree and intuitionistic otherwise.

Complex numbers and quantum dynamics — the reversible side of §3

  • σ(x, y) = (-y, x) — a length-preserving quarter-turn of the plane. Write i for σ: then σ(x,y) = (−y, x) is i·(x + iy) = −y + ix. It is reversible — lossless, and free on §3's effect axis.
  • σ²(x,y) = σ(−y,x) = (−x,−y) = −(x,y), so σ² = −1: σ is a square root of −1, its powers cycling 1, σ, −1, −σ — the four phases {1, i, -1, -i}. The plane with σ adjoined is ℝ[σ]/(σ²+1) = ℂ, and σ, a rotation, preserves length — it is unitary. So the complex numbers, the phases, and unitarity are generated by this one reversible operation. Unitary evolution is exactly §3's free, reversible side; the physics that costs — measurement, erasure — is the irreversible side (Landauer, §5).

  • Check: i ∂_t F = i ∂_t E − ∂_t B = i(∇×B) + ∇×E = ∇×(E + iB) = ∇×F, using the two Maxwell equations; splitting real and imaginary parts gives them back. Classical electromagnetism and single-particle quantum mechanics are the same equation.
  • ‖F‖² = ⟨E+iB, E+iB⟩ = ‖E‖² + ‖B‖² — the Hermitian cross terms ±i⟨E,B⟩ cancel. Conservation is forced, not named: from ∂_t F = −i∇×F,
$$ \tfrac{d}{dt}\,\lVert F\rVert^2 \;=\; 2\,\mathrm{Re}\,\langle F,\ \partial_t F\rangle \;=\; 2\,\mathrm{Re}\,\langle F,\ -i\,\nabla\times F\rangle \;=\; 2\,\mathrm{Im}\,\langle F,\ \nabla\times F\rangle \;=\; 0, $$
  • because curl is self-adjoint — ∫ F·(∇×F) = ∫ (∇×F)·F by parts with no boundary term — so ⟨F, ∇×F⟩ is real and its imaginary part vanishes. The generator −i∇× is therefore skew-adjoint: the flow preserves length, i.e. is unitary.

Search

$$ \text{solutions of } F \;=\; F^{-1}(\text{true}) \;=\; \{\, w : F(w) = \text{true} \,\}, \qquad \#\text{solutions} = \sum_{T \subseteq C} (-1)^{|T|}\, 2^{\,n - r(T)} $$
  • F : assignments → {true, false}. Solutions S_F = F⁻¹(true). For 3-SAT a clause forbids exactly one setting of its 3 literals, so the assignments that break it fill a subcube V_α — those 3 bits fixed to the forbidden setting, the other N−3 free (a codimension-3 face); every assignment either satisfies all clauses (in S_F) or lies in some V_α, and S_F is disjoint from ⋃ V_α, so Q_N = S_F ⊍ ⋃ V_α — deciding and solving are two observations of one partition. Count by inclusion–exclusion: #S_F = Σ_{T⊆C} (−1)^{|T|} |⋂_{α∈T} V_α|. When the clauses in T can be violated together, |⋂_{α∈T} V_α| = 2^{N−r(T)} with r(T) the coordinates they jointly fix; when two of them demand opposite values on a shared variable the intersection is empty and contributes 0. Regroup the sum per assignment by the j clauses it breaks: its weight is Σ_{i≤j} C(j,i)(−1)^i = (1−1)^j, which is 1 only at j = 0 — each solution survives once, the rest cancel.
  • Deciding = ‖S_F‖ (one bit: is S_F inhabited — a proposition, one point when true). Solving = S_F (a vertex with its membership proof). The truncation τ : S_F → ‖S_F‖ sends every witness to that one point, so its fibre is all of S_F (fibτ ≅ S_F, the §0 shape) — the one-bit decision discards exactly the which-witness fibre, with no left inverse once |S_F| > 1.
  • Decide = verify. For the machine's step f, deciding an input a completes it to (answer, witness) — by §1 that completion is the equivalence A ≅ Σ (b) f⁻¹(b), here decide(a) = (f a, (a, refl)): the answer, paired with the input and the refl proof it maps there. verify reads the witness's pre-image back out; the round trip is refl. Deciding and verifying are thus the two directions of that one equivalence, unique by §1 — the decided witness carries its own acceptance as refl, so nothing is searched between having the answer and having its certificate: the lossless run produces the witness with the answer — one forward pass, no second search — and verifying is that pass reversed. The one-bit decision ‖S_F‖ above is the lossy projection that throws the witness away (τ); the lossless machine never does. What complexity calls the find/check gap is not an operation between deciding and verifying — it is the length of the one run, and §5 showed no cardinality measures length. No counting separates finding from checking; the gap is a distance, and distances are not counts.

verify-inverts-decide f a = refl

  • #SAT = Σ_{T compatible} (−1)^|T| 2^{N−r(T)} = Σ_r (−1)^r M_r — the alternating collapse of the clause-intersection (factorial-moment) tower M_r = Σ_{|T|=r} |⋂ V|; the scalar count is an extremely lossy projection (1,−1,1,…)·(M_r). UNSAT ⇺ it is 0; an exactly-3 UNSAT formula needs m ≥ 8 clauses — writing ν(x) for the clauses assignment x violates, each clause is violated by 2^{N−3} assignments and UNSAT means every x violates at least one, so Σ_x ν(x) = m·2^{N−3} ≥ 2^N, i.e. m ≥ 8, sharp.
  • §5's cost is a geodesic potential, never a cardinality. Assignment, vertex, intersection, and fixed-order residual-width counts all collapse under factoring or coordinate change (disjoint triples: m clauses on disjoint variable-triples each kill 1 of 8 and leave 7, so #SAT = 7^m while the intersections number 2^m; inner-product ⟨x,y⟩ mod 2: read all of x first and the state reached must fix the map y ↦ ⟨x,y⟩ — distinct x ≠ x′ give different maps, disagreeing at y = e_i wherever x_i ≠ x′_i, so the 2ⁿ inputs force 2ⁿ distinct states, width 2ⁿ; read the pairs x_i, y_i interleaved and it is a running parity — remember x_i (2), fold x_i y_i in (2) — width ≤ 4). A lower bound is a Φ with Φ(t)=0 and Φ(u) ≤ w(u,v)+Φ(v) on every primitive edge; distance is the greatest such Φ. Since Φ rises by at most one per edge (unit incidence), an exponential lower bound is an exponential family of states the geodesic cannot merge — nonfillable boundary distinctions; the construction fixes exactly what counts as one, and posits no such family for SAT.
