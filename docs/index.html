Respecting Equality: Complete Inference, Deterministic and Step-Optimal

Avik Jain · avikj@berkeley.edu

Equality of types is equivalence — Voevodsky's univalence — and it computes. The interval and the Glue type former build it with nothing assumed (§§0–2): an isomorphism A ≃ B becomes an identification A ≡ B whose transport is that isomorphism, so isomorphic structures are interchangeable by a program that runs.

Two facts stand on that. A step is reversible exactly when it is transport along such an identification (3.2); every additive measure of what a step destroys vanishes on the reversible ones (3.5), so reversible computation dissipates nothing and a step's only cost is the information it erases — its Landauer heat (§3). And the diagonal is a single lemma (Lawvere): a point-surjective table forces every endomap a fixed point, so a fixed-point-free map forbids the table — Cantor, Russell, Tarski, the halting problem; Gödel is that lemma together with representability and ω-consistency (§4).

They meet in the result (§5): proving, deciding, computing and answering are one act — build a term, normalize it. The answer is the term's unique normal form (5.18), reached in a number of steps fixed by where the reduction begins and ends and not by the strategy between them (5.13), and that number is already the least possible (5.17). Complete inference is thus deterministic and step-optimal; and where a question has no answer, the diagonal is what establishes it, in place of a search that never ends (5.19).

Read elsewhere, the same construction is the natural numbers as finite sets up to relabelling (§6); the complex numbers, and Maxwell's equations as one Schrödinger equation, as its reversible side (§7); and Boolean search as partition by output, where the gap between finding a solution and checking one is exactly the bit a lossy truncation discards (§8). §9 then runs all of it on one problem, end to end — ordering a finite set, where the cost is fixed by how its size is written as a sum. At each result the computational core is a term machine-checked against the cubical library, printed where it is proved.

0. The one fact

Definition 0.1 (type, function, dependent pair). A type is a collection of values, written a : A. A function f : A → B maps values to values. For a family P — one type P a for each a : A — the dependent pair Σ[ a ∈ A ] P a holds pairs (a , w) with w : P a.

Definition 0.2 (identity type). Equality is a type: x ≡ y is the type of proofs that x equals y, with refl : x ≡ x. A proof is a value you keep.

Definition 0.3 (the interval). 𝕀 has two endpoints 0 and 1, a meet ∧, a join ∨, and an operation ~ that exchanges the endpoints and reverses order. The laws are: ∧ and ∨ are associative, commutative and idempotent, absorb one another (x ∧ (x ∨ y) = x) and distribute over one another, with 0 the unit of ∨ and 1 of ∧; and ~ 0 = 1, ~ 1 = 0, ~ ~ x = x, ~(x ∧ y) = ~x ∨ ~y. The unit interval [0,1] with min, max and 1 − x satisfies all of this and is a usable picture; what is used below is only these laws, never any property of the real numbers. "Free De Morgan algebra on one generator" is the exact name for that restriction: the elements are the expressions built from one symbol i by ~, ∧ and ∨, and two are equal only where the laws just listed force it. It is built, not assumed.

Definition 0.4 (path). A proof of x ≡ y is a map p : 𝕀 → A with p 0 = x and p 1 = y. refl is the constant map.

Definition 0.5 (contractible). A is contractible when some point of it exists and every element is equal to that point — the whole type collapses onto it.

Definition 0.6 (transport). For a family P, a proof p : x ≡ y gives transport p : P x → P y.

Proposition 0.7 (reversibility of transport). transport is reversible and loses nothing: it runs backward along the reversed path λ i → p (~ i), and transport refl x ≡ x — moving nowhere changes nothing.

Proof. Reversal is ~ from the interval (0.3) applied to the map of paths (0.4). For the second, note what is and is not being claimed: transport refl x is not the same term as x — Agda rejects refl as a proof of it, since transp (λ i → refl i) i0 x has still to be computed — but it is path-equal to x, which is what ≡ asserts and all that is used below. The path is built by filling the constant line (transportRefl in the library). ∎

Theorem 0.8 (the one fact). Σ[ y ∈ A ] (x ≡ y) — the values equal to x, each with its proof — is contractible, with centre (x , refl).

Proof. The path from the centre to any (y , p) slides along p itself: at stage t sit at the point p t, holding as its proof the piece of p from x up to t, which shows x ≡ p t. At t = 0 that is (x , refl); at t = 1 it is (y , p). The piece of p up to t is λ j → p (t ∧ j) — the i ∧ j of the term below. Its two ends follow from 0.3 alone: at j = 0 it is p (t ∧ 0) = p 0 = x, and at j = 1 it is p (t ∧ 1) = p t. So it is a path from x to p t, which is the proof the pair at stage t must carry. That is the whole use of ∧ here: it cuts a path off at a point. ∎

Remark 0.10 (transport is J). transport (0.6) is exactly J for a goal that ignores the proof — C(y , p) = P y — so transport (0.6) and J (0.9) are one thing. (The identity type's eliminator is its initiality as an inductive family: Awodey–Gambino–Sojakova 2012.)

Remark 0.11 (what the base is). Everything below — transport, J, function extensionality, univalence (§2) — is built from the interval (0.3) and one thing done with it: paths compose, and can be pushed along one another (the filling of 2.4), which each type former supplies for its own type. Of the interval's operations, ∧ builds the contraction in the one fact (0.8), ~ reverses a path in reversibility of transport (0.7), and ∨ earns its place in 2.4, where a square is closed from two of its sides. No axiom is added about any type.

Remark 0.12 (what §1 does). §1 is the one fact (0.8) with x replaced by a function's output.

1. Partition by output

Definition 1.1 (the inputs over an output). For f : A → B and b : B, write

f⁻¹(b)  =  Σ[ a ∈ A ] (f a ≡ b)

— the inputs that land on b, each kept with its proof that it does.

Theorem 1.2 (partition by output). A ≃ Σ[ b ∈ B ] f⁻¹(b).

Proof. Forward a ↦ (f a , (a , refl)); backward (b , (a , p)) ↦ a. Both round trips are refl, the return using the kept proof p : f a ≡ b. Nothing is lost, only regrouped. ∎

  where
  fwd  = λ a → f a , a , refl
  bwd  = λ (b , a , _) → a
  rinv = λ (b , a , p) i → p i , a , λ j → p (i ∧ j)

Definition 1.3 (completion). A completion of f is a family T assigning a type T(b) to each b, together with an equivalence A ≃ Σ[ b ∈ B ] T(b) that respects the output map — an input's b is unchanged.

Theorem 1.4 (the partition is the only one). Every completion of f is f⁻¹.

Proof. Respecting the output map means the equivalence carries the piece over each b to the piece over that same b; by the partition (1.2) the inputs over b on the right are exactly T(b), so it carries f⁻¹(b) onto T(b). A completion is therefore a choice, at each b, of a type equivalent to f⁻¹(b). The types equivalent to a fixed one form a contractible type (2.4), and a per-b choice among contractible options is again contractible (2.5). So T = f⁻¹: the decomposition is forced, not a chosen encoding. ∎

Remark 1.5 (what §1 rests on). The partition (1.2) stands on §0 alone. Its uniqueness (1.4) is the one place §1 looks forward, borrowing univalence (2.4) and function extensionality (2.5). Every decomposition later in the page is that partition: group by output, keep the inputs over each b.

2. Isomorphism is substitution

Definition 2.1 (equivalence). A ≃ B is maps both ways with proofs that they cancel: runnable in both directions, nothing lost either way. This is the lossless match the partition (1.2) asserts.

Proposition 2.2 (two sides of one thing). f has a two-sided inverse if and only if f⁻¹(b) is contractible for every b.

Proof. An inverse g centres f⁻¹(b) at (g b , ·), and the cancellation laws contract every (a , p : f a ≡ b) onto that centre (0.5). Conversely, choosing the centre of each f⁻¹(b) is an inverse. ∎

Remark 2.3 (property against data). The two sides (2.2) are not the same type. Contractible-fibred is a property, true in at most one way; an inverse is data, which may be given differently. The second is the one carried around.

Theorem 2.4 (univalence). ua : (A ≃ B) → (A ≡ B), and it computes: transportua(e) = e. Hence Σ[ X ] (X ≃ Y) is contractible.

$$ (A \simeq B)\ \simeq\ (A \equiv B), \qquad \mathsf{ua} : (A \simeq B) \longrightarrow (A \equiv B), \qquad \mathrm{transport}^{\,\mathsf{ua}(e)} \;=\; e $$

Proof. The primitive is the interval (0.3): a path is a map out of the interval (0.4), and paths can be joined end-to-end and pushed along one another — Kan composition, which is what runs transport. The second ingredient is Glue, a type former whose defining property is exactly what is wanted: given a type B, and on part of the boundary a type A with an equivalence A ≃ B, it yields a type that is A on that part of the boundary and B elsewhere. Apply it along one interval coordinate with A and e at the 0 end: the result is a map 𝕀 → Type sending 0 to A and 1 to B, which by 0.4 is a path A ≡ B, and transport along it is e. Contractibility is then the one fact (0.8) read at the universe, with ≡ between types supplied by ua. Voevodsky's axiom, built from the interval and Glue (Cohen–Coquand–Huber–Mörtberg 2018). ∎

Corollary 2.5 (function extensionality). Functions that agree at every argument are equal.

Proof. Given h : (x : A) → f x ≡ g x, the map λ i x → h x i is a path f ≡ g by paths (0.4) — the interval is pulled out of the argument. ∎

Remark 2.6 (structures interchange). By univalence (2.4) isomorphic structures interchange by a program, losslessly. This is the fact used by 1.4.

3. A step is reversible when its input can be recovered

Definition 3.1 (reversible). A step is reversible when some map sends its output back to its input, so it runs backward as well as forward, losing nothing (2.1). By reversibility of transport (0.7), transport and every equivalence are of this kind.

Theorem 3.2 (every reversible operation is a transport). A reversible operation is transport along a path, namely the one its own reversibility names, and that path is the only one inducing it.

Proof. Maps both ways whose round trips are the identity are an equivalence (2.1, 2.2), which ua turns into a path A ≡ B (2.4). Transport along that path is the operation, by univalence (2.4)'s computation rule. Uniqueness is ua being an equivalence, again univalence (2.4). ∎

module _ {A B : Type ℓ} (f : A → B) (g : B → A)
         (fg : (b : B) → f (g b) ≡ b) (gf : (a : A) → g (f a) ≡ a) where

  -- Its reversibility IS an equivalence, so it names a path.
  its-equivalence : A ≃ B
  its-equivalence = isoToEquiv (iso f g fg gf)

  its-path : A ≡ B
  its-path = ua its-equivalence

  -- And transport along that path is the operation itself.
  reversible-is-transport : (a : A) → transport its-path a ≡ f a
  reversible-is-transport a = uaβ its-equivalence a

  -- The path is the only one that induces it: ua is an equivalence.
  the-path-is-unique : pathToEquiv its-path ≡ its-equivalence
  the-path-is-unique = pathToEquiv-ua its-equivalence

Definition 3.3 (effect-cost). A step is irreversible when several inputs share one output b: then which of them the input was is gone. That forgotten "which one" is the only thing a step can ever destroy. Its effect-cost is the entropy of the input given the output: log₂ of the number of inputs mapping to b when those are equally likely (2ᵏ inputs give k bits), and less when they are not — the count is the most it can be. This is one of the two axes; the other is the number of steps taken (5.7).

Proposition 3.4 (Landauer's principle). Destroying k bits dissipates at least k · k_B T ln 2 of heat, with k_B Boltzmann's constant and T the temperature; a reversible step dissipates 0.

Proof. Landauer in units (5.9), which derives it from reversibility (3.1) and effect-cost (3.3). ∎

Theorem 3.5 (reversibility costs nothing, for any measure). Let ℓ be any ℕ-valued measure that adds under composition with ℓ e = 0. Then ℓ g = 0 wherever g has a right inverse — no group laws are used.

$$ \ell(g) + \ell(g^{-1}) = \ell(\mathrm{id}) = 0 \;\Longrightarrow\; \ell(g) = 0 \qquad (\text{naturals} \ge 0) $$

Proof. A sum of naturals is 0 only when each summand is. ∎

Remark 3.7 (what is lost). The only thing a computation ever loses is an input it chose to forget. How many steps it takes to reach the answer is the length axis (5.7), treated in §5.

4. The diagonal

Definition 4.1 (point-surjective). Picture e : A → (A → B) as a table whose row a is the function e a; reading row a at its own index gives e a a, the diagonal. Call e point-surjective when every h : A → B appears as some row, with the row index produced:

onto e  =  (h : A → B) → Σ[ a ∈ A ] (e a ≡ h)

The Σ is untruncated, which is why the fixed point below comes out as a value you can hold.

Theorem 4.2 (Lawvere 1969). If e : A → (A → B) is point-surjective then every g : B → B has a fixed point.

$$ \Big(\forall\, h : A \to B.\ \ \Sigma\, a : A.\ \ e\,a \equiv h\Big) \;\Longrightarrow\; \Big(\forall\, g : B \to B.\ \ \Sigma\, b : B.\ \ g\,b \equiv b\Big) $$

Proof. Put h a := g (e a a), the twist of e by g. Point-surjectivity gives a₀ with e a₀ ≡ h, so

$$ e(a_0)(a_0) \;\equiv\; h(a_0) \;\equiv\; g\big(e(a_0)(a_0)\big) $$

and e a₀ a₀ is a fixed point of g. ∎

The proof reads e at one argument only, so the hypothesis can be weakened to exactly what it uses: it is enough that e hits the single function h. That weaker form, lawvere-one-row in the box, is what the diagonal lemma (4.6) and halting (4.10) supply, where only the definable or computable functions are rows.

Corollary 4.3 (contrapositive). If some g : B → B has no fixed point, no e : A → (A → B) is point-surjective.

private variable A B : Type

-- φ is point-surjective: every B-valued observation on A is a row of φ.
PtSurj : (A → (A → B)) → Type
PtSurj {A = A} {B = B} φ = (g : A → B) → Σ[ a ∈ A ] φ a ≡ g

-- Read the row at its own index, then apply f.
twist : (A → (A → B)) → (B → B) → (A → B)
twist φ f a = f (φ a a)

-- The argument reads φ at ONE argument, so one row is the whole hypothesis.
lawvere-one-row : (φ : A → (A → B)) (f : B → B)
  → Σ[ a ∈ A ] (φ a ≡ twist φ f) → Σ[ b ∈ B ] f b ≡ b
lawvere-one-row φ f (a₀ , hit) = φ a₀ a₀ , sym (funExt⁻ hit a₀)

-- Lawvere 1969: a point-surjective φ forces every endomap of B a fixed point.
lawvere : (φ : A → (A → B)) → PtSurj φ → (f : B → B) → Σ[ b ∈ B ] f b ≡ b
lawvere φ surj f = lawvere-one-row φ f (surj (twist φ f))

-- Contrapositive: one fixed-point-free f kills point-surjectivity of every φ.
noFix→noPtSurj : (φ : A → (A → B)) (f : B → B)
  → ((b : B) → ¬ (f b ≡ b)) → ¬ PtSurj φ
noFix→noPtSurj φ f nofix surj = nofix (lawvere φ surj f .fst) (lawvere φ surj f .snd)

-- not has no fixed point: not true = false and not false = true.
not-no-fix : (b : Bool) → ¬ (not b ≡ b)
not-no-fix true  p = true≢false (sym p)
not-no-fix false p = true≢false p

-- Cantor, as the B = Bool, f = not instance (not has no fixed point).
cantor : (φ : A → (A → Bool)) → ¬ PtSurj φ
cantor φ = noFix→noPtSurj φ not not-no-fix

The impossibility theorems are Lawvere (4.2) or the contrapositive (4.3) at a named (B , g). Each instance below supplies only that naming.

Corollary 4.4 (Cantor). No e : A → (A → 2) is point-surjective.

Proof. The contrapositive (4.3) with B = 2, g = ¬: negation swaps true and false, so it has no fixed point. (A → 2) is the decidable subsets of A by characteristic functions — not every subset, which would be maps into propositions. ∎

Lemma 4.5 (representability). Work in a theory with sentences, a derivability predicate ⊢, negation, and a provability formula Prov — the box names these Sent, Pf, neg, prov. Code each one-variable formula by a number and let sub(m , n) be the code of formula m with the numeral n̄ substituted for its variable. Then sub is represented by a formula.

Proof. sub is primitive recursive, and every primitive-recursive function is represented by a formula: induct on how it is built — the base functions (zero, successor, projection) are formulas, and composition and primitive recursion stay first-order by quantifying, boundedly, over the finite run that computes the value. A base as weak as Robinson's Q suffices. ∎

Theorem 4.6 (the diagonal lemma). For every formula ψ there is a sentence G with ⊢ G ↔ ψ(⌜G⌝).

Proof. Lawvere (4.2) in the one-row form, at the table e(m)(n) = sub(m , n): row m is the formula coded by m, and reading row m at its own index is sub(m , m). The row 4.2 needs is the twist's, and that it is a row is representability (4.5), nothing more — the full notion of 4.1 is false here, most families of formulas being cut out by no formula, which is why the one-row form is the one that fires. Concretely, for g = ψ the twist δ(x) := ψ(sub(x , x)) is a formula, has a code d, and the fixed point G := δ(d̄) has code sub(d , d). The B this fires over is the sentences up to provable equivalence, where ↔ is equality, so g b = b read there is exactly ⊢ G ↔ ψ(⌜G⌝). The box records formulas, their application, and the fixed point just built as the interface HasDiagonal, and reads it in the ¬Prov form as diagonalGivesGoedelFix. ∎

Corollary 4.7 (Gödel, first conjunct). Take ψ = ¬Prov, so 4.6 gives G with ⊢ G ↔ ¬Prov(⌜G⌝) — G says I am unprovable. If the theory is consistent and satisfies D1 (⊢ s ⇒ ⊢ Prov⌜s⌝), then ⊬ G, and by soundness G is true.

Proof. goedelHalfOne in the box. If ⊢ G then D1 gives ⊢ Prov⌜G⌝, and the forward half of the fixed point (4.6) gives ⊢ ¬Prov⌜G⌝, contradicting consistency. Prov(⌜G⌝) is the formula a proof of G exists — one unbounded existential over a decidable proof-check, which is what Σ₁ names — so G's unprovability is its truth. ∎

Proposition 4.8 (the second conjunct is a further hypothesis). Consistency, D1 and the fixed point do not give ⊬ ¬G.

Proof. noHalfTwo runs any claimed derivation of ⊬ ¬G against the four-sentence model Wit in the box — ⊤, ⊥, g, ¬g with Prov constantly ⊤. It is consistent, satisfies D1, and carries the fixed point at g — whose two arrows are both vacuous, not by accident but in every model of these hypotheses: those already force ⊬ g (fixIsAlwaysVacuous, from 4.7) and ⊬ ¬Prov⌜g⌝ (provNegEmpty), so neither arrow ever receives an input. What Wit alone adds is that ¬g is provable — so no such derivation exists. Wit fails exactly where it must: OmegaBad, proving Prov⌜g⌝ yet not g — consistent but ω-inconsistent. (In a real arithmetic that gap is consistency surviving because the asserted proof is a nonstandard one no numeral names; Wit is the same separation stripped to four points and no arithmetic.) ∎

Theorem 4.9 (Gödel's first incompleteness theorem). If the theory is also ω-consistent, and its logic carries contraposition, double-negation elimination and transitivity internally, then G is independent: ⊬ G and ⊬ ¬G.

Proof. independenceFromRepresentability in the box. The first conjunct is 4.7. For the second, the backward half of the fixed point (4.6), ¬Prov⌜G⌝ → G, contraposed and cleared of its double negation (internalFix), gives ¬G → Prov⌜G⌝; so ⊢ ¬G would force ⊢ Prov⌜G⌝ alongside ⊬ G (4.7) — the OmegaBad that 4.8 exhibits and ω-consistency forbids. ∎ (Rosser 1936 lowers ω-consistency to plain consistency by changing the fixed point.)

open import Cubical.Foundations.Prelude

private variable ℓ : Level

-- A theory: sentences, a derivability predicate Pf, negation, and the
-- internal provability operator prov (already "the formula at a code").
record Theory (ℓ : Level) : Type (ℓ-suc ℓ) where
  field
    Sent : Type ℓ
    Pf   : Sent → Type ℓ
    neg  : Sent → Sent
    prov : Sent → Sent
open Theory public

Consistent : Theory ℓ → Type ℓ
Consistent T = (s : Sent T) → Pf T s → Pf T (neg T s) → ⊥

HBL1 : Theory ℓ → Type ℓ                       -- D1:  ⊢ s  ⇒  ⊢ Prov⌜s⌝
HBL1 T = (s : Sent T) → Pf T s → Pf T (prov T s)

GoedelFix : (T : Theory ℓ) → Sent T → Type ℓ   -- ⊢ G ↔ ¬Prov⌜G⌝
GoedelFix T G =
  (Pf T G → Pf T (neg T (prov T G))) × (Pf T (neg T (prov T G)) → Pf T G)

OmegaBad : (T : Theory ℓ) → Sent T → Type ℓ    -- ⊢ Prov⌜G⌝ yet ⊬ G
OmegaBad T G = Pf T (prov T G) × (¬ Pf T G)

Independent : (T : Theory ℓ) → Sent T → Type ℓ
Independent T s = (¬ Pf T s) × (¬ Pf T (neg T s))

-- Conjunct 1 (⊬ G): the fixed point's forward half, D1, consistency.
goedelHalfOne : (T : Theory ℓ) (G : Sent T)
  → Consistent T → HBL1 T → GoedelFix T G → ¬ Pf T G
goedelHalfOne T G con d1 (fwd , _) pG = con (prov T G) (d1 G pG) (fwd pG)

-- …so ⊬ G in EVERY such model, and the fixed point's forward arrow is
-- vacuous there — not a quirk of Wit below. Only ⊢ ¬G can still vary.
fixIsAlwaysVacuous : (T : Theory ℓ) (G : Sent T)
  → Consistent T → HBL1 T → GoedelFix T G → (Pf T G → Pf T (neg T (prov T G)))
fixIsAlwaysVacuous T G con d1 gf pG = Empty.rec (goedelHalfOne T G con d1 gf pG)

-- …and its backward arrow too: ⊢ ¬Prov⌜G⌝ would give ⊢ G through it.
provNegEmpty : (T : Theory ℓ) (G : Sent T)
  → Consistent T → HBL1 T → (gf : GoedelFix T G) → ¬ Pf T (neg T (prov T G))
provNegEmpty T G con d1 gf pNP = goedelHalfOne T G con d1 gf (snd gf pNP)

wneg wbot = wtop
wneg wg   = wng
wneg wng  = wg

Corollary 4.10 (halting). No total H decides, of an arbitrary machine and input, whether it halts.

Proof. Running code a on input x is partial, so it is no table of total functions; a total halting-decider H makes it one, since φ(a)(x) := if H(a,x) then run(a,x) else 0 is then total. Every total computable h : A → 2 is a row of it: take any program for h; it halts everywhere, so H never diverts it. Now Lawvere (4.2) at g = ¬, in the one-row form: the twist δ(a) := ¬ φ(a)(a) is total and computable, hence a row, so δ ≡ φ(d) for some code d, and reading row d at its own index gives φ(d)(d) = ¬ φ(d)(d), which ¬, having no fixed point, forbids. ∎

Corollary 4.11 (Russell, Tarski). The non-self-members are no set's membership, and no truth predicate is definable.

Proof. The contrapositive (4.3) twice. Russell: B the propositions, g = ¬ on x ∈ x — the non-self-members are the diagonal row, and ¬ fixes nothing. Tarski: B the truth values, g = ¬ — a truth predicate would make the liar a fixed point of negation. ∎

Theorem 4.12 (Kleene's recursion theorem — the positive reading). Where e has a section — e being the interpreter, sending a code to the function it runs, and the section the compiler, sending a function to a code for it — Lawvere (4.2) hands every g a fixed point: a program equal to its own transform, the quine.

Proof. Lawvere (4.2) unchanged. The fixed-point-free instances — Cantor (4.4), halting (4.10), Russell–Tarski (4.11) — read it where g has no fixed point and conclude against e; here e is given and the conclusion is kept. ∎

Corollary 4.13 (Rice). No decider exists for a nontrivial semantic property of programs.

Proof. Suppose one, and take programs a that has the property and b that lacks it. By the recursion theorem (4.12) build a program which reads its own code, runs the decider on it, and then behaves like b if the verdict is yes and like a if no. Either verdict is wrong about it. ∎

Remark 4.14 (one lemma, many instances). There is no family of impossibility theorems: one lemma (4.2), applied at a different (B , g) each time, read in the other direction for the recursion theorem (4.12), and — at Gödel (4.6–4.9) — carrying the extra arithmetic hypotheses the diagonal alone does not supply. Rice sits on that second side rather than among the fixed-point-free instances.

Remark 4.15 (the fixed points are built). Because the Σ of point-surjectivity (4.1) is untruncated, 4.2 returns a fixed point as a value, and each instance inherits that: 4.6 builds the Gödel sentence goedelSentence with its own code sub(d , d), 4.10 builds the diagonal program δ, and 4.12 builds the quine. The classical statements assert that such a thing exists; here each is produced by the term in the box, instantiated at its own (B , g).

5. Complete inference is deterministic and step-optimal

§§0–2 supply substitution along an equality (0.6, 2.4), §3 reversibility (3.1), §4 the diagonal (4.2). This section fixes a machine, defines two costs on it, and proves the result stated at the top. The division of labour is worth stating once: §§0–4 are the semantics — what a proof, an answer and a reversible step are — and §5.2 fixes the machine they run on. Every cost result below is a theorem about that machine, and takes exactly one property of it: the one-step diamond (5.11).

5.1 Terms, proofs, questions

Definition 5.1 (the correspondence). Each connective is read as a type former:

A ⇒ BA → B, the function type: a proof sends a proof of A to one of B
A ∧ BA × B, the pair
A ∨ BA ⊎ B, the tagged sum
falsehood⊥, the empty type
∀ x. P x(x : A) → P x, the dependent function
∃ x. P xΣ[ x ∈ A ] P x, the dependent pair
modus ponensapplication
checking a proofnormalizing its term: running it until no step is left

For the first four rows — the propositional part, with sums and the empty type — the connectives and the type formers are one structure: the free bicartesian closed category (Curry 1934; Howard 1969; Lambek 1980). The two quantifier rows go past it, since their types depend on a value; the setting for those is a locally cartesian closed category, which is what §0 has been building.

Definition 5.2 (question, answer). A computation is a term of a value type, a decision a term of Dec P = P ⊎ ¬ P, an answer a term of the type the question asks for. The answer to a question is the normal form of that term.

Proposition 5.3 (one operation). Proving, deciding, computing and answering are one operation: build the term, normalize it.

Proof. Immediate from the correspondence (5.1) and questions and answers (5.2): the four differ only in which type the term inhabits. ∎

5.2 The machine

Definition 5.4 (net). A cell has one distinguished principal port and finitely many auxiliary ports. A net is a finite set of cells with a partial matching of their ports by wires. The distance between two cells is the number of wires on a shortest path between them.

Definition 5.5 (interaction step). An active pair is two cells whose principal ports are wired to each other. For each pair of cell kinds a rule gives a net R on exactly the auxiliary wires of those two cells:

$$ \dfrac{\;(c_1,c_2)\ \text{an active pair of}\ N \qquad (c_1,c_2) \longrightarrow R\;}{\;N \longrightarrow N[(c_1,c_2) := R]\;} $$

Every other cell and wire of N is unchanged. Write Step s t for one such step.

Definition 5.6 (trace, length, normal form).

data Trace : ℕ → S → S → Type where
  done      : {s : S} → Trace zero s s
  stepTrace : {n : ℕ} {s u t : S} → Step s u → Trace n u t → Trace (suc n) s t

Normal : S → Type
Normal t = (u : S) → Step t u → ⊥

The length of a trace is its index n.

5.3 Two costs

Definition 5.7 (the two axes). The length of a reduction is the number of steps it takes (5.6). Its effect-cost is the quantity defined in 3.3: the entropy of its input given its output.

Proposition 5.8 (the two costs of a step). A reversible step has effect-cost 0 and length 1. A step merging 2ᵏ inputs into one output has effect-cost k and length 1.

Proof. A step whose input can be recovered is a bijection (3.1), so one input shares each output and log₂ 1 = 0; a 2ᵏ-fold merge gives log₂ 2ᵏ = k. Neither touches the step count. ∎

Proposition 5.9 (Landauer's bound, in units). A step of effect-cost k dissipates k · k_B T ln 2 of heat, and a reversible step dissipates 0.

Proof. Reversibility (3.1) and effect-cost (3.3) read twice — once on the datum, once on the dynamics carrying it. A 2 → 1 merge of microstates is an entropy drop of ln 2 nats, k_B ln 2 once k_B converts nats to thermodynamic entropy. Reversibility (3.1) splits the ambient dynamics into two cases. Injective: the two microstates the step merged stay distinct in it, so the distinction the datum lost is now in the surroundings, as heat T ΔS, with T the conversion of entropy to energy that defines temperature. Non-injective: it is a merging step itself, and effect-cost (3.3) charges it the same k one level down. Both cases pay k bits; k_B and T convert that to joules. By the two costs (5.8) a reversible step has k = 0, so the drop is 0 and the heat is 0. ∎ (Landauer 1961; Bennett 1973, 1982 named it.)

Remark 5.10 (what the price covers). The effect-cost is charged against the observation: the bits erased for the requested output, not for a whole trace. The length cost is a separate axis, bounded by a potential (5.15) and by no count of solutions (Search).

5.4 Every reduction is the shortest

Lemma 5.11 (one-step diamond). If Step s a and Step s b then a ≡ b, or there is c with Step a c and Step b c.

Proof. Two distinct active pairs are disjoint: distinct principal-port pairs cannot share a cell. By interaction (5.5) each step leaves everything outside its own pair untouched, so doing one leaves the other available and untouched, and the two converge in one further step each. This is structural to interaction nets (Lafont 1990), not an assumption. It is also why the machine is nets and not terms: β-reduction is confluent but has no one-step diamond — two overlapping β-redexes need several steps to reconverge, which is why the classical proof goes through parallel reduction — so the equal-length result below is false for it. A rule firing on an active pair cannot overlap another, by the disjointness just shown, and that is the whole difference. ∎

Lemma 5.12 (peel). Step s u → Trace (suc n) s t → Normal t → Trace n u t.

Proof. Induction on the trace's length. Apply the diamond (5.11) to the given step and the trace's first step: either they merge, and the tail is the required trace, or they reach a common term, from which the inductive hypothesis peels the shorter tail. At a normal form no step is left to carry, so the given step is absorbed exactly once. ∎

Theorem 5.13 (equal length). Trace n s t → Trace m s t → Normal t → n ≡ m.

Proof. Induction on the first trace, peeling its first step through the second by peel (5.12). ∎

module RandomDescent (S : Type) (Step : S → S → Type)
  (diamond : {s a b : S} → Step s a → Step s b
    → (a ≡ b) ⊎ (Σ[ c ∈ S ] (Step a c × Step b c))) where

  data Trace : ℕ → S → S → Type where
    done      : {s : S} → Trace zero s s
    stepTrace : {n : ℕ} {s u t : S} → Step s u → Trace n u t → Trace (suc n) s t

  Normal : S → Type
  Normal t = (u : S) → Step t u → ⊥

  -- Any available first interaction removes exactly one unit from any
  -- terminating reduction to the same normal form. It cannot detour.
  peel : {n : ℕ} {s u t : S} → Step s u → Trace (suc n) s t → Normal t → Trace n u t
  peel {zero} jump (stepTrace first done) normal with diamond first jump
  ... | inl same             = subst (λ v → Trace zero v _) same done
  ... | inr (z , left , right) = Empty.rec (normal z left)
  peel {suc n} jump (stepTrace first rest) normal with diamond first jump
  ... | inl same             = subst (λ v → Trace (suc n) v _) same rest
  ... | inr (z , left , right) = stepTrace right (peel left rest normal)

  normal-length-zero : {n : ℕ} {s t : S} → Normal s → Trace n s t → n ≡ zero
  normal-length-zero normal done                     = refl
  normal-length-zero normal (stepTrace first rest)   = Empty.rec (normal _ first)

  zero-endpoints : {s t : S} → Trace zero s t → s ≡ t
  zero-endpoints done = refl

  -- All complete reductions of THIS object to THIS normal form have one length.
  same-normalization-length : {n m : ℕ} {s t : S}
    → Trace n s t → Trace m s t → Normal t → n ≡ m
  same-normalization-length done other normal = sym (normal-length-zero normal other)
  same-normalization-length {m = zero} (stepTrace first rest) other normal =
    Empty.rec (normal _ (subst (λ s → Step s _) (zero-endpoints other) first))
  same-normalization-length {m = suc m} (stepTrace first rest) other normal =
    cong suc (same-normalization-length rest (peel first other normal) normal)

  normalization-is-geodesic : {n m : ℕ} {s t : S}
    → Trace n s t → Trace m s t → Normal t → n ≤ m
  normalization-is-geodesic chosen competitor normal =
    subst (_ ≤_) (same-normalization-length chosen competitor normal) ≤-refl

Corollary 5.14 (the length is fixed by the endpoints). Every reduction of a term to its normal form has the same length, so each is the minimum: the step-count is fixed by the endpoints, never by the strategy, and the cost is as deterministic as the answer.

Proof. Equal length (5.13) with ≤-refl, as normalization-is-geodesic in the box. ∎

Theorem 5.15 (Bellman). In the reduction graph — vertices terms, edges steps of cost c(u→v) — call Φ a potential when Φ(normal form) = 0 and Φ(u) ≤ c(u→v) + Φ(v) on every edge. Then every potential is a lower bound on every finishing path, and where a normal form is reachable the geodesic distance is the greatest potential, satisfying

$$ \Phi(\text{normal form}) = 0, \qquad \Phi(u) = \min_{v}\, \big[\, c(u \to v) + \Phi(v)\,\big] $$

Proof. Adding the edge inequality along any path to a normal form, where Φ = 0, gives Φ(u) ≤ the path's total cost. The geodesic distance satisfies both conditions, so it is a potential, and it meets the bound with equality at the cheapest edge (Bellman 1957). By minimality (5.14) it is attained by every reduction, so there is nothing to minimise over. ∎

Theorem 5.16 (unit lookahead). An output that must read input at distance n from it cannot be produced in fewer than n steps — a bound on every reduction, not on one chosen strategy.

Proof. By interaction (5.5) one step changes the datum only where its two cells sat, so its output at a position depends on that position and its one wired neighbour. Composing k steps, the output depends only on input within distance k of it in the net one started from: one step reaches a wired neighbour, so each widens the reach by exactly one. The rewriting does not let that slip — a rule replaces two cells by a net on their own auxiliary wires, and the cells it puts there can carry only what those two already held, so no interaction moves information further than one wire, however the distances in the rewritten net come out. ∎

Read from the other end, the same k is an information demand. Write x ≡ₙ y for agreement through observational depth n: the bound says x ≡ₙ₊ₖ y ⇒ w(x) ≡ₙ w(y) for every k-step w, so an output determined to depth n requires source read to depth n + k. One number, two orientations — elapsed interaction depth read dynamically, source information required read observationally — and both are the length axis (5.7), not a third cost: the effect-cost (3.3) counts what collides under an observation, this counts what must be read to produce it. In the observational orientation the criterion of 8.11 reads as a radius, since one step widens the source a position can consult by exactly one wire.

Corollary 5.17 (step-optimality). The native evolution attains the geodesic: no reduction is shorter than the one it takes.

Proof. Minimality (5.14). ∎

Theorem 5.18 (unique normal form). A term has at most one normal form.

Proof. The diamond (5.11), tiled. Take two reductions of one term; the diamond closes their first steps to a common term, and filling the grid step by step reconverges them. If both end at a normal form — nothing left to rewrite — that common reduct can only be each endpoint, so the two are equal. (Church–Rosser, here the diamond filled in.) ∎

Corollary 5.19 (the dichotomy). For every question there are two cases and no third. Either a normal form exists, and by minimality (5.14) and unique normal form (5.18) every reduction reaches that one answer in the one step-count the endpoints fix; or §4 proves there is none — a decider for one's own halting is among these, since asking for one asks for the fixed point the diagonal forbids — and the question had no answer to find, which the system establishes rather than running out of time looking.

Remark 5.20 (what well-formed names). Well-formed names the first case, and the reduction decides which case a question is in. What the dichotomy (5.19) fixes is reachability, not length: a long geodesic is a real price, charged honestly, and already the shortest (5.14).

5.5 What the length counts

Proposition 5.21 (the building route is the size of the answer). Take a rule set in which each interaction emits at most one constructor — true of the standard encodings, and a property of the rules rather than of interaction (5.5). The normal form is then a complete proof-carrying witness — the answer with its certificate — and the steps that build it number exactly its constructors.

Proof. Each building step emits exactly one constructor — one piece of the answer, a successor, a pair, a tag — so the building route's length equals the witness's size; building sucⁿ takes one successor per step. A term carrying extra redexes — spots still waiting to reduce, like (λx.x) t — clears those first, administrative steps building nothing, so its total length is its own geodesic by minimality (5.14) while the witness's size counts only the constructors built. Reading the finished term off is a fold that copies it, adding no step. ∎

Remark 5.22 (two exponentials). By the building route (5.21) the building route's length is the witness's size in unary. When that unary size is exponential in the question's succinct binary measure — as sucⁿ is, n against log n — the route is exponentially longer than the succinct measure. That exponential is the observer's lossy binary measure laid against a lossless unary object; change the measure, not the computation, and it is gone. The other exponential can be real: the geodesic length when a small witness ends a long reduction. That is a length, so no change of measure touches it; it is the reduction's own fixed distance, already the minimum by minimality (5.14).

Remark 5.23 (what is solved). The optimization problem — the fewest steps to an answer, what complexity theory exists to chase — is here solved: computation modeled as lossless reduction is optimal by construction, optimality its standing condition. The million wasteful ways to compute the same answer are departures from this model, not rival strategies within it. Only the diamond (5.11) is used, so 5.13–5.19 hold of any reduction that has the diamond.

Remark 5.24 (sharing). Sharing is written into the net. A shared subterm is held by a cell — a duplicator, wired in at ports like every other cell — so it belongs to the net's syntax, in place before any reduction begins: no bookkeeping outside the net itself, and the diamond (5.11) used only the disjointness of active pairs, not sharing. Its price is charged: a duplicator's interactions are steps on the length axis exactly like the rest, and on the effect axis they are free by the two costs (5.8), since folding along an equality is transport (0.6) and runs backward (0.7). What sharing buys is the one thing claimed for it: an active pair is never duplicated, so no step repeats work.

Remark 5.25 (termination). Where a term terminates it is reached in finitely many forced steps; a non-terminating term denotes a well-defined infinite (coinductive) object, not a gap.

Remark 5.26 (no outer layer). Evaluator, type-checker and optimizer are themselves terms of the same language, and a question about them is another term the same normalizer reduces. There is no meta-level, so no self-reference contradiction: reasoning about its own terms as data, it proves the §4 impossibilities as ordinary theorems — and, as those theorems say, it does not decide its own halting, and has a sentence it neither proves nor refutes (4.9) — which is 5.27’s case (b) twice over, since independence is the pair ⊬ G and ⊬ ¬G, two types established empty. Any expressible system, this one included, is lawful construction and identity, operated on exactly as everything else is: the language is its own metatheory, standing nowhere outside itself.

5.6 The result

Theorem 5.27 (complete inference). Let a declaration be any type — anything rationally stateable (the correspondence (5.1), 5.2). Pose it together with the identities available, which by uniqueness of the partition (1.4) is forced rather than a choice of encoding, and normalize. Then exactly one of two cases holds, and the reduction itself decides which:

(a) the declaration is inhabitable, and the normal form is an inhabitant of it — a proof, carrying its own acceptance as refl (decide = verify (8.6)) — reached in a number of steps fixed by where the reduction starts and ends (equal length (5.13)), which no order of applying the identities can beat (5.14, 5.17), and with no step repeating work (sharing (5.24));

(b) it is not inhabitable, and §4 names the obstruction: the system establishes that no inhabitant exists, rather than failing to find one (the dichotomy (5.19)). Case (b) is a statement about the declared type and never a term of a negation one level inside it — where the declaration is a theory’s provability of a sentence, establishing it empty is ⊬ G, not ⊢ ¬G (4.7, 4.8).

By no outer layer (5.26) this holds of declarations about the system itself.

Proof. One operation (5.3) makes proving, deciding, computing and answering the same act, so the four are this one statement. Unique normal form (5.18) makes the inhabitant unique; 5.13 makes every reduction to it the same length and 5.14 makes each one minimal; unit lookahead (5.16) is the matching lower bound; 5.19 supplies the two cases and no third. ∎

Remark 5.28 (the scope of the minimum). The minimum in complete inference (5.27) is over orders of applying the identities, not over choices of starting term: a different term inhabiting the same type has its own length. What 5.13 settles is that once the declaration is posed there is no search over methods left to perform — every way of following the identities takes the same number of steps, so none is cleverer than another, and only the identities remain to follow.

6. Numbers

Definition 6.1 (counting). To count a finite set is to forget which element is which. Any two n-element sets differ only by a relabelling, so all of them are one thing; what the forgetting throws away is exactly the relabellings, the n! permutations of n things. To count is to keep the class and discard Sₙ:

$$ \mathbb{N} \;=\; \{\text{finite sets}\}\,/\,\cong, \qquad \mathrm{Aut}(\text{an } n\text{-element set}) \;=\; S_n $$

Greek arithmetic states this construction outright. Euclid VII Def. 1–2 define the unit as "that by virtue of which each of the things that exist is called one" and a number as "a multitude composed of units" — so the unit is defined separately and is not itself among the numbers, which is identity's standing here too (0.2): it generates the sequence without being a term of it. And the units are athetos, without position: a monad is a position-less substance where a point is one having position (Aristotle, Metaphysics 1016b; Posterior Analytics 87a36). Position-less is the whole content of this definition. Units with no position have nothing to tell one from another, so a multitude of them carries nothing beyond how many there are, and every relabelling of it is the same multitude. That is Sₙ discarded, given as a definition rather than derived.

Proposition 6.2 (card). card is the bijection between iso-classes of finite sets and ℕ, with inverse n ↦ {1,…,n}.

Being a bijection and not a measurement, the number is the iso-class rather than a label attached to it. Aristotle marks exactly this as the Pythagorean position against the Platonic one (Metaphysics 1090a): number is not separated from the things.

Proposition 6.3 (arithmetic). Addition is disjoint union and multiplication is product:

|A ⊎ B| = |A| + |B|        |A × B| = |A| · |B|

Written in base b, adding two digit strings is this disjoint union done place by place, carrying whatever overflows a place into the next.

Proposition 6.4 (divisibility is a distributive lattice). d ∣ n iff each prime's exponent in d is ≤ its exponent in n. So gcd is the meet (minimum exponents) and lcm the join (maximum), and unique factorization sends n to its exponent vector, making ℕ the product of one chain per prime, where minimum and maximum distribute componentwise.

Theorem 6.5 (number theory and logic are one lattice). The divisor lattice carries the operations of propositional logic: gcd/lcm are ∧/∨, coprimality is disjointness, the divisibility order is entailment, and d ↦ n/d is an order-reversing involution satisfying De Morgan. So divisibility and the propositional connectives are one algebra — the same distributive lattice with involution, whether the elements are divisors or truth values — and 6.6 says when it is the Boolean one.

Proof. The product decomposition of the divisor lattice (6.4) matches the Chinese remainder theorem ℤ/mn ≅ ℤ/m × ℤ/n by x ↦ (x mod m, x mod n): injective, since coprime m, n both dividing x − y force mn ∣ (x − y), hence bijective by count. ∎

Proposition 6.6 (Boolean exactly on the squarefree). Being finite and distributive, the divisor lattice of every n is a Heyting algebra. It is Boolean iff n is squarefree.

Proof. What varies is whether the involution of 6.5 is the Heyting negation. On squarefree n it is: a divisor is a subset of the primes and n/d its complement. A repeated prime breaks it — on n = p² the divisors are the chain 1 < p < p², where the Heyting negation of p is 1 and ¬¬p = p² ≠ p, while the involution sends p to n/p = p. So the lattice is Boolean on squarefree n and properly intuitionistic otherwise. ∎

Definition 8.1 (solutions). For F : assignments → {true, false}, the solutions are the fibre (1.1) at b = true:

$$ \text{solutions of } F \;=\; F^{-1}(\text{true}) \;=\; \{\, w : F(w) = \text{true} \,\} $$

Write S_F for this type, and Q_N for the 2^N assignments.

Theorem 8.2 (the cube splits). Q_N = S_F ⊎ ⋃α V_α, where V_α is the subcube of assignments breaking clause α. Deciding and solving are two observations of this one partition.

Proof. The partition (1.2) at F. For 3-SAT a clause forbids exactly one setting of its three literals, so the assignments that break it fill a subcube V_α — those three bits fixed to the forbidden setting, the other N−3 free, a codimension-3 face. Every assignment either satisfies all clauses, so lies in S_F, or lies in some V_α, and S_F is disjoint from ⋃ V_α. ∎

Theorem 8.3 (the count).

$$ \#\text{solutions} \;=\; \sum_{T \subseteq C} (-1)^{|T|}\, 2^{\,N - r(T)} $$

Proof. Inclusion–exclusion on the cube splits (8.2): #S_F = Σ_{T⊆C} (−1)^{|T|} |⋂_{α∈T} V_α|. When the clauses in T can be violated together, |⋂_{α∈T} V_α| = 2^{N−r(T)} with r(T) the coordinates they jointly fix; when two of them demand opposite values on a shared variable the intersection is empty and contributes 0. Regrouping per assignment by the j clauses it breaks, its weight is Σ_{i≤j} C(j,i)(−1)^i = (1−1)^j, which is 1 only at j = 0: each solution survives once, the rest cancel. ∎

Definition 8.4 (deciding, solving). Solving is S_F — a vertex with its membership proof. Deciding is ‖S_F‖, writing ‖·‖ for the proposition that this is inhabited: one bit, and when true a single point, every witness collapsed onto it. The truncation is τ : S_F → ‖S_F‖.

Theorem 8.5 (what the one bit discards). The pre-image of τ is S_F itself, and τ has no left inverse once |S_F| > 1.

Proof. τ sends every witness to the one point, so by the fibre (1.1) its pre-image is Σ[ w ∈ S_F ] (τ w ≡ pt). Since ‖S_F‖ has any two of its points equal, the equality component carries nothing, and the pre-image is S_F. The one-bit decision therefore discards exactly the which-witness pre-image. ∎

Theorem 8.6 (deciding and verifying are one equivalence). For the machine's step f, decide(a) = (f a , (a , refl)) and verify reads the witness's pre-image back out; the round trip is refl.

Proof. Deciding an input a completes it to an answer with a witness, and by the partition (1.2) that completion is the equivalence A ≃ Σ[ b ] f⁻¹(b), unique by uniqueness of the partition (1.4). The two directions are decide and verify. The decided witness carries its own acceptance as refl, so the lossless run produces the witness with the answer in one forward pass, and verifying is that pass reversed: no operation sits between them for a gap to live in. ∎

9. Ordering — what counting discards

One problem, taken end to end. Sorting is where a reader is most certain that a method has to be chosen, and it is where the construction says there is nothing to choose. The fibre is §1, the halving is §2, keeping the permutation is §3, the two costs are §5’s, and the number being sorted is §6’s. Nothing below is added to the construction; all of it is used.

Definition 9.1 (sorting). To sort a finite set is to assign it indices matching its order — to compute the ordering, delivered as a sequence. The orderings of n elements number n!, and each comparison restricts which of them survive.

Theorem 9.2 (the fibre is the relabellings). The fibre of sort over a sorted sequence is the n! rearrangements of it: a list is a sorted list together with a permutation, and nothing besides.

Proof. The partition (1.2) at sort, whose fibre (1.1) over a sorted sequence is the inputs landing on it, and forced rather than chosen by 1.4. ∎

Counting (6.1) discards exactly these relabellings to reach the number; sorting recovers the one the order names. The two are one forgetting, run in opposite directions. Keep the permutation and the run destroys nothing (3.6); deliver the sorted sequence alone and the effect-cost (3.3) is log₂ n!, the size of the fibre.

Proposition 9.3 (a comparison is a restriction). A comparison leaves exactly the orderings consistent with its outcome. Comparing two elements about which nothing is known leaves half, since exchanging them is a bijection between the orderings answering one way and those answering the other (2.6). A comparison already implied leaves all of them and is never made: what is held is a partial order, so from a < b, b < c, b < d the relations a < c and a < d are there already, the n² pairs never stored.

Proposition 9.4 (which comparison). Naming any still-unordered pair is not enough: a supply offering (a,b), then (a,c), then (a,d) spends n−1 comparisons to learn only which element is least. The one that excludes most is wanted. Of the twenty-four orderings of four elements, a < b leaves twelve. Comparing c with d halves those to six; comparing a with c instead leaves eight when a wins — a least of three, one of three equally — so its worse outcome is worse than six. Fresh pairs are taken while any remain. With a < b and c < d the six survivors are the C(4,2) interleavings, and comparing the two least leaves three either way, where comparing b with c leaves five in one outcome, b < c forcing abcd alone. The least are compared, and the result is one component with a known least, below everything in both. Five comparisons in all, and ⌈log₂ 24⌉ = 5.

Theorem 9.5 (why the least halve). A comparison between two elements exchanged by a symmetry of what is already known splits the survivors exactly in half.

Proof. The exchange carries orderings consistent with what is known to orderings consistent with it and swaps the two outcomes, so it is a bijection between them (2.6), and two sets in bijection are equal halves of their union. Two runs of equal length are exchanged by the symmetry that interchanges them, which carries least to least. No symmetry of a < b, c < d exchanges b with c, which is why that comparison is lopsided. ∎

Each such comparison establishes a new least for the two components it joins; every relation already established stays, and the loser remains least of its own run. Two fresh elements are always so exchanged, so a fresh pair always yields one.

Definition 9.6 (merge). Sortedness unfolds into one recursion, and merge is that unfolding:

Sorted(x)  =  head x ≤ every element of tail x  and  Sorted(tail x)

merge(x, y)  =  head x ≤ head y  ?  head x ∷ merge(tail x, y)
                                 :  head y ∷ merge(x, tail y)

A single comparison is merge running on two one-element runs. Sorting is the composition of merges and nothing else, beginning from the elements as runs of length one.

Theorem 9.7 (every + is a merge). Writing n as a sum is choosing the merges. Each + is one merge of two runs and costs the sum it produces, so the cost of sorting is the sum of the intermediate sums — equivalently, each element pays once for every + above it.

(1+1)+(1+1)        2, 2, 4              cost  8  =  n log₂ n
1+(1+(1+1))        2, 3, 4              cost  9
n = 8, balanced    2,2,2,2, 4,4, 8      cost 24  =  n log₂ n
n = 8, chained     2,3,4,5,6,7,8        cost 35

Proof. A merge of runs of lengths a and b emits a + b elements, and under a rule set emitting one constructor per step (5.21) that is a + b steps: the sum it produces. Summing over the + signs counts each element once for each + standing above it, which is its depth. ∎

This counts steps, one per element emitted. The comparisons are fewer — a merge of a and b makes at most a + b − 1, since the last run empties without one — and they are bounded separately, below.

Remark 9.9 (the shape of the obligation). Write Φ for log₂ of the orderings still consistent. It is zero exactly at the one that survives, but it is not a potential in the sense of Bellman (5.15), which asks Φ(u) ≤ 1 + Φ(v) on every edge: a comparison falling the unlikely way can drop it by much more, and with a < b, c < d the outcome b < c takes it from log₂ 6 to zero. That bounds the deepest route rather than every route, and the bound is log₂ n! comparisons, which some orderings beat. It is the shape 8.11 describes — obligations of which a step discharges at most one — at a scale that is not exponential, and it is met: merging equal runs makes at most n log₂ n − n + 1 comparisons for n = 2ᵏ, each of the n − 1 merges making one fewer than the sum it produces — for n = 4 that is 5 = ⌈log₂ 24⌉, the bound met exactly, and for n = 8 it is 17 against 16. The count it bounds is comparisons, not the steps of 9.7.

Corollary 9.10 (the two smallest). Theorem 9.11 (the shape is the numeral). The balanced sum is the binary representation of n, and the chain is the tally.

Proof. For n = 2ᵏ each element has a k-bit index, and the path from the root of the sum down to it spells that index: the first layer of merges joins indices differing in the last bit, the next those differing in the second-to-last. Resolving the ordering one layer at a time is resolving it one bit of the index at a time. For general n the runs are the 1-bits: 13 = 8 + 4 + 1. Counting is merging — add elements one at a time, keep runs matching the binary form of the count, and each carry merges two equal runs into one twice the size, which is 6.3's carrying read at its cost. The gap between the two costs is the gap between a tally and a numeral. Succession gives a line; place value gives a log₂ n-dimensional cube, which is what a base system has always been. A set indexed by the naturals already carries that structure, so there is no reason to prefer succession unless the input arrives as a line.

Proposition 9.12 (the same factorisation from the other end). Read downward, that product of binomials is a partition rather than a composition: at the top, which half of the set lies below and which above — C(n, n/2) ways — then the same within each half, down to single elements. Every element is sent toward its own index, as though searching for its own position one bit at a time. Merge splits by position and builds from the leaves; this splits by value and descends from the root. Splitting by value is partition by output (1.2), the output being where the element lands, so the two directions are that one partition taken at the two ends of the same factorisation, and inverting the permutation exchanges them.

Proposition 9.13 (the space of orderings). Take the orderings as points, joining two when they differ by swapping neighbours in the sequence. For three elements the six close into a hexagon:

            abc
          /     \
       bac       acb
        |         |
       bca       cab
          \     /
            cba

The distance from an ordering to the sorted one is its number of out-of-order pairs, since each swap of an out-of-order neighbouring pair fixes exactly one. Every route that only fixes out-of-order pairs therefore has the same length whatever order the swaps are taken in — not by the diamond (5.11), which fails here, but by Bellman (5.15): the out-of-order count is a potential that every such swap meets with equality — the swap costs one and lowers the count by exactly one — and a potential met with equality on every edge of the reduction makes every route a geodesic. (A swap of an in-order pair raises the count instead; it is not a step of the reduction, and a route using one is longer.) Two swaps at disjoint positions do commute and their routes close a square, the diamond where it holds; three sharing an element close the hexagon above, where it does not — those two reconverge only after two further swaps on each side, not one — and both sides are still the same length. So the picture reaches 5.13’s conclusion through 5.15, and shows the diamond failing on the way. A comparison is a cut through this space, and one already implied is a cut that misses what remains.

Proposition 9.14 (comparisons and swaps). Comparisons count cuts and swaps count distance, and the counts differ: about log₂ n! comparisons are needed (9.9), while the swaps are the out-of-order pairs (9.13), of which there are at most the n(n−1)/2 pairs. One comparison can authorise several swaps, and that is the whole of the gap — the two axes (5.7), with both numbers in hand.

Proof. In the set there are no swaps at all — comparisons add knowledge and the order is learned, not moved; swaps belong to the sequence presentation. At a single pair the two coincide: one comparison, one swap, one edge of 9.13. Above that they part. Merging [a,b] with [c,d] and learning c < a gives c < b free from the a < b already held, so one comparison authorises both swaps. Every swap is backed by a comparison made or inherited, and in a sorting that wastes nothing most are inherited. ∎

Remark 9.15 (the declaration). Nothing above chooses a method. The declaration is Σ[ B ] (B is a rearrangement of A) × Sorted B, and by 9.2 the completion is forced, not searched for. Posing it with the identities available and normalising (5.27) is the sorting: merge is sortedness unfolded (9.6), the shape is the numeral rather than a policy (9.11), the information is fixed by the endpoints (9.8), the cost is the sum of the intermediate sums (9.7). The sums that cost more are not rival methods but the same number written another way (5.23). Sorting is where the choice of method looks least avoidable, and there is none to make: pose the declaration with the identities the object actually has, and what remains is to follow them. What is learned is fixed by where the sorting starts and ends (9.8); what it costs was fixed when the number was written as a sum (9.7); and the sum is part of what was posed, not something chosen along the way.

10. Sharing — the balance a free network keeps

Information copies, so sharing it destroys nothing (3.6). What follows asks when sharing is nonetheless withheld, and what the single obstruction costs. The fibre is §1, the two axes and the vanishing grading are §3, the distance bound is §5, and the sums are §9’s. Nothing below is added to the construction; all of it is used.

Definition 10.1 (state, trajectory, future-value). A state is the information held — internal together with external observable. From a state the admissible transitions each carry a local value delta, and iterating them gives the trajectory type over that state. Future-value is a functional on that type, accumulated along a trajectory, and over branches either by max — the path taken — or by sum — the branch set held.

Definition 10.2 (the increment). For information I′ received at a state I, write V[I′, I] = V[I + I′] − V[I]. The object is the increment; no absolute is required to exist.

Theorem 10.3 (information is never worse, and only because nothing is retracted). If the trajectory type over I + I′ contains the one over I and the local deltas are nonnegative, then V[I′, I] ≥ 0 under either accumulator, and along a received sequence of information the future-value at each next state is monotonically nondecreasing.

Proof. max over a superset is at least max over the subset, and a sum of nonnegatives over a superset is at least the sum over the subset. ∎

The containment is the whole hypothesis, and it holds exactly when information accumulates. If I′ corrects I rather than extending it, a trajectory that was admissible is withdrawn and the value falls. So the monotonicity of value and the absence of reconciliation are one condition, not two: a store that only grows.

Remark 10.4 (the trajectory type is a fibre, and both accumulators are already here). The trajectories admissible from a state are the inputs over it (1.1), growing the state is an inclusion of those fibres, and the decomposition by state is forced rather than chosen (1.4). Value is then a monotone functional on an expanding fibre and nothing further is assumed of it. The two accumulators are the two the page already uses: max is the form Bellman (5.15) fixes for any functional over paths, and sum is the alternating accumulation over the whole branch set at the moment tower (8.8). Only the first is realisable by an agent, which takes one trajectory; only the second is additive over disjoint branch sets.

Theorem 10.5 (exclusivity is the only obstruction to sharing). Sharing information lowers no party’s future-value unless some transition raises one party’s while lowering another’s, and that requires a resource whose acquisition by one removes trajectories from the other.

Proof. By 10.3 each party’s value is monotone in its own information, so a loss can only come from the trajectory type itself shrinking. Receiving information never shrinks it; only the environment moving does. An environment move shrinks X’s trajectories exactly when it removes a transition X had, which for a move made by Y means Y took something X can no longer take. ∎

Read as a prescription: acquire whatever information is available, since by 10.3 none of it can lower the acquirer; and release all of it except what identifies an access some other party’s acquisition would remove. The first half has no exception. The second has exactly one, and it is this theorem’s hypothesis.

So withholding is not a primitive of this construction and needs no separate justification. It is forced by the exclusivity structure, in the amount that structure forces, and is zero elsewhere.

Definition 10.6 (the two forms of scarcity). A resource is cyclic when it is acquired, held for an interval, and released to the pool it came from, the pool undiminished — the unit is exclusivity over the interval. It is consumable when acquisition is its use and its use is its destruction — the unit is the quantity.

Theorem 10.7 (an eternal resource is scarce in position, not in quantity). A cyclic resource whose pool no number of holds diminishes is eternal: it is neither destroyed nor consumed. What a hold consumes is the holder’s own interval of access, and two parties cannot hold the same interval at the same place. The scarcity is a spatio-temporal exclusion, and no quantity counts down.

Proof. By 10.6 a cyclic hold returns the pool undiminished, so iterating holds leaves the pool where it was and nothing about it is a decreasing quantity. A hold is the occupation of one interval at one place, and two occupations of the same pair exclude each other; so the exclusion is over pairs, which are what a hold spends. ∎

Burning a fuel to do work consumes the fuel. Standing in an unbounded continuous stream consumes no part of the source — only the window in which one stands. Time spent with a book is spent and the book is returned. In each case the consumed thing belongs to the holder and not to the pool, which is why the pool admits no ledger.

Theorem 10.8 (the two forms are the two axes, one each). Consumption is effect-cost. A cyclic hold has effect-cost zero for every measure, and its only cost is length: the interval occupied.

Proof. Consuming merges several inputs into one output, and what is forgotten is which input it was — effect-cost (3.3), with Landauer (3.4) attached. Acquire, hold and release compose to the identity on the pool; the holder’s own state changed, the pool’s did not. So on pool-transformations the cycle has a right inverse, and by the vanishing grading (3.5) every ℕ-valued measure additive under composition with ℓ(id) = 0 is zero on it — no group laws used. What remains is the other axis (5.7). ∎

Copying is the degenerate cyclic case: a read leaves the source as it was, so it is reversible and free on the effect axis (3.6), and its only cost is the steps taken to obtain it. Charging a consumption cost for cyclic access charges effect-cost to a step with a right inverse, which 3.5 says is zero.

Theorem 10.9 (where nothing is exclusive, circulation needs no argument). Releasing a held cyclic resource is preferred when the gain fed back through other parties’ enlarged trajectory types exceeds one’s own loss of exclusivity, and that loss is nonzero only on exclusive holdings.

Proof. Releasing enlarges the trajectory type of whoever takes it, which by 10.3 raises their future-value, and their subsequent transitions act on the environment the releaser also inhabits. The releaser’s own loss is the trajectories that required holding it, which is the exclusivity of 10.5. ∎

The same obstruction as 10.5, read on circulation rather than on information. One condition governs both.

Theorem 10.10 (the release condition carries two losses, not one). Releasing also enlarges the taker’s trajectory type by transitions that remove the releaser’s other exclusive holdings. So the loss is the trajectories that required the hold (10.9) together with the trajectories the taker gains against everything else the releaser holds exclusively, and release is preferred when the fed-back gain exceeds their sum.

Proof. By 10.3 the taker’s enlarged type is a superset, so it may contain transitions it did not contain before, and by 10.5 a transition of the taker lowers the releaser exactly when it takes something the releaser can then no longer take. Nothing confines such a transition to the resource released. ∎

So the one obstruction of 10.5 enters a single decision twice — once on the thing released, once on everything else held. A party holding nothing else exclusively faces only the first term, and a party holding nothing exclusively at all faces neither.

Definition 10.11 (the balance, with its slack). For a total c shared between two parties, the balance is

Balance c = Σ[ x ∈ ℕ ] Σ[ y ∈ ℕ ] Σ[ d ∈ ℕ ] (x + y + d ≡ c)

The unheld remainder d is a variable, so the constraint is an equality at every moment rather than an inequality to be checked. Nothing is imposed by this but a bookkeeping: it is chosen so that simultaneous use by both parties respects x + y ≤ c, and it is not derived from anything above.

Theorem 10.12 (a pairwise constraint fixes a point or bounds a range). Two quantities held at distinct nodes are independently free until a constraint relates them. An equality identifies them: one value stands in two places, and only one of the two remains free. An ordering leaves both free and bounds each by the other’s current value. The balance is the equality case, and its slack is what lets an inequality be carried as one.

Proof. An equality between two variables has one solution for each value of either, so the pair has as many states as one of them alone — the other has stopped being a free variable. An ordering has, for each value of one, a nonempty range of the other wherever the order is not already tight, so neither loses its freedom and what is lost is extent. The balance of 10.11 is an equality on three quantities of which the third is free, so the pair is held to x + y ≤ c while the equality itself is exact at every moment. ∎

This is the difference between identifying two points across nodes and ordering them. Identification is the stronger act: it removes a dimension, and by §0 an identification is exactly what the construction transports along. An ordering removes none and is checked, not transported.

Theorem 10.13 (the slack is determined by the shares). The third component is a proposition: given x and y there is at most one d.

Proof. Two slacks give (x + y) + d ≡ (x + y) + d′, and cancellation on the left gives d ≡ d′; the proof components then agree because ℕ is a set. ∎

Theorem 10.14 (lowering is unilateral and raising is gated, by the types). A party may lower its own share with no counterparty in the hypothesis. A party may raise its own share only from a hypothesis that presents the slack as k + d, and there is no term of that type without the presentation.

release : (x′ k y d c : ℕ) → (x′ + k) + y + d ≡ c → x′ + y + (k + d) ≡ c
claim   : (x y′ k d c : ℕ) → x + y′ + (k + d) ≡ c → x + (y′ + k) + d ≡ c

Proof. Both are one rearrangement of a sum composed with the hypothesis; the box checks them. release mentions only the releasing party’s own decomposition x′ + k, so it needs nothing received. claim’s hypothesis is the grant: the slack exhibited in the form the raise consumes. ∎

A transfer is the two composed, and the total is untouched by either. The slack is the only intermediary, so the parties never hold a joint object — each rewrites its own component against a presentation of the remainder.

Theorem 10.15 (lowering is a path, not a step). A party may reach any x′ ≤ x by any descending sequence, with every intermediate value admissible and every step unilateral; the composite of lowerings is a lowering, and the slack it creates is the sum of the slacks its steps create.

Proof. release of 10.14 composed with itself, the two grants added. Its hypothesis mentions only the releasing party’s own decomposition, so no step of the sequence requires a counterparty, and no intermediate state is distinguished. ∎

Remark 10.16 (the signal is a ratchet, so its order carries nothing). Lowering is what creates the slack a raise consumes, and announcing it fixes the announcer’s own upper bound at the lowered value. The announced total therefore only grows, the recipient takes the greatest it has heard, and a repeated or late announcement changes nothing — the state after a set of announcements is a function of the set.

Theorem 10.17 (a budget tree is a writing of the total as a sum). Partitioning c into local budgets, each node holding its own slack, recursively, is a writing of c as a sum of ones; the constraint composes by one induction, with every check local to a node and its children.

Proof. If each node’s children’s shares and slack sum to that node’s share, then by induction on the tree the leaves’ shares sum to at most the root’s. Each step of the induction mentions one node and its children only. The shapes available are the ways of writing the number as a sum, which is the choice of merges (9.7). ∎

So §9 is this tree’s theory and nothing further is needed. What a partition settles is fixed by its endpoints along every shape (9.8), so a subtree may be rewritten freely under the constraint from above without changing what is authorised; and if the cost of a shape is taken to be the total of the intermediate budgets, the cheapest is the balanced one (9.10), which is the total in binary (9.11).

Theorem 10.18 (a subtree may be rewritten under the bound it inherits). The constraint entering a node is that node’s whole interface: nothing above it depends on the shape below. So a subtree may repartition itself into any shape satisfying its own root’s share, with no announcement upward and no effect on a sibling.

Proof. 10.17’s induction mentions one node and its children only, so a proof for a subtree composes with the proof above it through the root’s share alone. Two subtrees with the same root share are therefore interchangeable in that induction, which is what it means for the shape below to be unobservable above. ∎

The shapes available below a node are the writings of its share as a sum (9.7), and choosing among them is local. This is the autonomy the tree buys, and it is the same statement as 10.17 read downward instead of upward.

Remark 10.19 (the budget bounds width, never length). An action acquires one unit, holds it for an interval and releases it, so by 10.8 its entire cost is the interval. The total therefore bounds simultaneous holding and nothing else: with one unit, unboundedly much work runs in sequence.

Theorem 10.20 (composing holds is how a dependency is written, and the two compositions are the two accumulators). Two actions in sequence occupy the sum of their intervals with one unit; two in parallel occupy the greater of their intervals with two. A dependency between actions is written by composing their holds, and the sum and max of 10.1 are exactly these two compositions.

Proof. A sequential pair reuses the unit, since the first releases before the second acquires, so one unit suffices and by 10.19 the cost is the intervals added. A simultaneous pair cannot reuse it, so the count adds and the occupied interval is the longer of the two. Adding along a sequence is sum; taking the longer of concurrent branches is max. ∎

So the two accumulators of 10.1 were not a choice between measures. They are the length axis and the width axis (10.8), and a dependency graph of actions is read on one or the other according to whether its parts share a unit.

Theorem 10.21 (a party can prove only the quantity that constrains it). Allocation received is provable by the holder; return made is not, and the gap is one quantity per edge.

Proof. A counterparty needs an upper bound on what the holder may still use, which is allocation received minus return made. A stale reading of a quantity that only grows yields a lower bound on it. A lower bound on allocation received makes the usable amount smaller, which is safe. A lower bound on return made makes it larger, which is not. So the freshness requirement falls on the second quantity alone, and the same snapshot of a holder is consistent with the moment before its return. ∎

Hence allocation is certified by the allocator, with a chain of receipts to the root, and a return is complete only when the party it constrains has signed for it. The trust that moves is no longer in the returning party but in the allocator not over-allocating, and that recurses to the root.

Theorem 10.22 (a stale offer forks rather than transitions). An offer made against a snapshot taken before a return and accepted after it is accepted into a state that no longer exists, so the acceptance creates a branch. What a counterparty needs fresh is therefore not a quantity but a position in the offerer’s own order of its own events.

Proof. Acceptance is a transition out of the state the offer names. If that state has been left, the transition has no source in the current history, and the two histories agree only on a prefix — which is a branch and not a step. A position in the offerer’s order decides whether the named state has been left; the quantity in the offer does not, since the same quantity occurs before and after unrelated events. ∎

Remark 10.23 (a held grant leaves nothing to understate). If budget exists only as a grant held, and returning hands the grant back, then misreporting a return gains nothing: what is spent is the grant and not a number. What remains is presenting one grant twice, which is a second use of a thing whose fibre carries one.

Theorem 10.24 (a return completes on the acknowledgement below, and the two directions are counted by different parties). A return is complete only when the party below acknowledges it, so it is one event held by both. Allocations then accumulate downward, each carrying its chain to the root, and returns are counted upward by the party that received them. No party reports its own returns.

Proof. By 10.21 allocation received is provable by the holder and return made is not. The gap closes not by a better report but by moving the count to the party for whom that return is an allocation received, where the same argument makes it provable. Acknowledgement is what makes that count complete: a return no party has recorded is a return that has not occurred, so the acknowledgement is not evidence of the return but part of it. ∎

So each of the two quantities at a node is exhibited by whichever party receives it, and neither party is asked for a quantity it alone can see. The unprovable direction of 10.21 has no occurrences left.

Theorem 10.25 (where the trust moved). After 10.24 the party below need not trust the party above’s account of what it returned. What remains to be trusted is that the party above allocated no more than it held — a claim about a total rather than about conduct, and a total is what a receipt chain exhibits (10.21).

Proof. The downward total at a node is provable there by 10.21 and the upward total is provable there by 10.24, so both sides of that node’s balance are exhibited by a party for whom they are allocations received. The only quantity left unexhibited is whether the node’s own allocations downward exceeded what it held, which is a statement relating that node’s two totals and is checked where they meet — the cut at that node (10.26). ∎

The trust is not removed. It is relocated to the one place the construction can present it as an identity between two quantities the same party already holds.

Theorem 10.26 (the invariant is a law at every cut, not at a time). For each cut of the system into a part and its environment, inflow equals outflow together with the residue held or dissipated inside. The family of such laws, agreeing where cuts overlap, is the invariant; no global time appears in it, and each party checks its own boundary alone.

Proof. A cut is a partition of the parties, and the flows crossing it are the inputs over that boundary (1.1). A family assigning to each cut a local balance that respects the flow map is a completion of it, and by 1.4 every completion is that partition — so the family is forced rather than chosen, and agreeing on overlaps is automatic. ∎

This is what a globally serialised record is for, obtained without one. A serialisation produces a single order over all events; the cut-law holds at every cut, including the ones a single order cannot name, and is checked locally.

Theorem 10.27 (the invariant is carried as a hypothesis and never observed). No party observes the law of 10.26. Each carries it as an induction hypothesis over its own finite history and, for its persistent parts, a coinduction hypothesis over their unfoldings. The only serialisation required anywhere is each party’s own order on its own events; no global time occurs in the statement, and none is needed to enforce it.

Proof. By 10.26 the law is a family of boundary statements agreeing on overlaps. A party’s own boundary statement is a proposition about its own history, so it is proved by induction on that history, which needs only that party’s own order. A persistent part has no last event, so its statement is proved by coinduction on its unfoldings instead (10.1). Agreement on an overlap is agreement between two boundaries, which is one cut and so again local. ∎

This is why nothing here needs a global serialisation of flows. What a global order would be for — making the invariant observable at a time — is not what enforces it; the hypothesis is.

Theorem 10.28 (a closed cycle is invisible to every cut it does not cross). A flow that returns to where it began contributes zero to the balance at any cut it does not cross, so it requires no visibility outside itself. What requires agreement is only what nets across a cut.

Proof. The contribution of a flow to a cut is its net crossing; a closed cycle crosses each cut an equal number of times in each direction, or not at all. ∎

The exception is the cycle that has not closed. A unit in flight is indistinguishable from net transport to anyone outside, so the quantity 10.21 requires fresh and the quantity that limits this invisibility are the same one: what is currently held. What such a flow is made of, and what it conserves, is 10.29.

Theorem 10.29 (a flow with no net at any cut is a composition of cycles, and cycles superpose). By 10.28 a closed cycle contributes nothing at any cut it does not cross, so a flow netting zero at every cut is composed of closed cycles alone. These compose with sign: two cycles sharing an edge add on it where their orientations agree and cancel where they oppose. The rotation that generates such a flow and the quantity it conserves are §7’s.

Proof. A flow netting zero at every one-node cut has equal inflow and outflow at each node, and a flow with that property decomposes into closed walks: follow any edge carrying flow, continue by conservation at each node, and a finite graph forces a repeat. Removing that closed walk leaves the property intact, so induction exhausts the flow. Superposition is addition of per-edge values, and it is signed because one edge traversed oppositely contributes oppositely. ∎

So eddies that come into being, compose and vanish are not an analogy here: the conservative part of any flow is a sum of cycles, interfering on shared edges, and the generator of the rotation is the quarter-turn of 7.2.

Remark 10.30 (what is not derived). Value here is relative to the party holding the state: 10.1 is a functional on that party’s trajectory type, and 10.5 turns on one party’s rising while another’s falls. There is no network-wide quantity above, and none is conserved. The balance of 10.11 is imposed, chosen so that simultaneous use is safe, and the construction supplies only what follows from it once chosen — that lowering needs no permission, that raising cannot be written without a grant, that the tree is a sum, and that the law holds at every cut. That an eternal resource exists at all (10.7) is a claim about the world and not a theorem; that a party acknowledges a return (10.24) is a condition on the protocol and not a consequence of it; and 10.25 relocates a trust rather than removing one.

11. Flow — the thread, the circuit, and what each hop keeps

§10 asked when information is withheld and what the withholding costs. This section asks what moves, what each hop does to it, and the two kinds of walk that result. What a quotient costs was fixed at 3.3, what a rewrite is at 5.5, what a hop cannot beat at 5.16, how a total is written as a sum at 9.7, and where a law has to hold at 10.26. Nothing below is added to the construction; all of it is used.

Definition 11.1 (the packet). Information moves along paths of connected peers. A packet is a persistent object on such a path, carrying its accumulated interaction history and the code that acts on it, each node updating both.

Theorem 11.2 (a forwarding path is a continuation chain, and the join is what costs). n peers each making at most one call and never calling itself is tail position only, so the packet is the continuation and no stack exists anywhere. A forward is then a step on the length axis alone; a sequential call is a wait for an emitted packet to terminate, and that wait is where the cost sits.

Proof. Forwarding carries the packet unchanged but for its own trace, so it is reversible and free on the effect axis (3.6), leaving the length axis (5.7). A sequential call cannot proceed until two traces — the caller’s and the callee’s — are identified at a point, and branching copies the packet so that two copies share a trace prefix; the content such a rejoin settles is the interleaving, fixed by the endpoints along every schedule (9.8). ∎

So the floor on a dependency is the distance bound (5.16) with distance counted in peers: an output that must read input n hops away cannot be produced in fewer than n forwards, for every route and not for a chosen one. And a subproblem handled by a loop on a subnetwork is a cycle in this flow, so by 10.28 it is invisible outside once closed, and is the open case until then.

Definition 11.3 (the two primitives). Information dynamics has two operations and no others: transport, moving a packet between peers, and local interaction, a rewrite at one node. The two axes are theirs, one each — transport spends length and destroys nothing (3.6); interaction is where everything destroyed is destroyed (3.3).

This is what makes the phenomenon local and global at once. Every operation is at one node or along one edge, and nothing in the construction is anywhere else; the global object is the composition of those, and no party holds it. The two axes were already the two costs (5.8), and there are two because there are two primitives.

Definition 11.4 (the hop). A node receiving a packet acts on it by its own value: the component of the packet indivisible from that node’s own value-maximisation is kept and carried on, and the remainder is quotiented out. A hop that keeps everything is a forward; a hop that keeps less is productive. The node appends what it contributes before the packet leaves.

The interaction has three outputs, not one: the node’s next state, the outgoing packet, and the peer it goes to. The target is produced by the reaction between the packet and the state the node already held — it is not a routing decision taken beside the computation, and no table is consulted for it.

Theorem 11.5 (a thread is a reaction sequence, so §5 holds of it). The hop of 11.4 is a rewrite on an active pair: the packet together with the node holding it. Two hops of one thread at distinct nodes are disjoint, so a thread is a reduction sequence in the sense of 5.5, and the one-step diamond (5.11), equal length (5.13), the length fixed by the endpoints (5.14), unit lookahead (5.16), step-optimality (5.17) and the unique normal form (5.18) all hold of it with nothing further assumed. The single exception is two packets of one thread at one node, which share that node’s state and so are not disjoint.

Proof. An active pair here is a packet and the node holding it, and a hop consumes exactly that pair and produces the next (11.4). Two such pairs at distinct nodes share no cell, which is the disjointness 5.11 requires, so the diamond closes them and the rest of §5 follows from the diamond as it does there. Two pairs at one node share the node’s state, so 5.11’s hypothesis fails. ∎

So the order in which concurrent hops occur changes neither where a thread ends nor how long it takes, and no node needs to look further than one hop ahead to act step-optimally. The whole of §5 transports to the network unchanged. The one place order matters is the exception, and that is the join (11.17) — which is why branching is the only part of this that needs an argument.

Theorem 11.6 (the packet splits, and the whole cost of a hop is its quotient). Write the packet as what it inherited together with what the path has contributed. Each quotient acts on the inherited part alone and never enlarges it; each contribution enlarges the contributed part and never touches the inherited one. The inherited parts of a thread therefore form a filtration, and the hop’s effect-cost is exactly what its quotient discards.

Proof. The quotient is a surjection out of the inherited part, so by effect-cost (3.3) it is charged the pre-image it merges and nothing else. Appending is a rearrangement, which is reversible, and by 3.5 costs nothing for any measure. The inherited parts are nested because each is the image of the last. ∎

Remark 11.7 (the quotient is productive, not merely restrictive). What leaves a node is not a subobject of what arrived: the kept component is composed with what the node already holds, so the outgoing packet can carry strictly more than the incoming one. Only the inherited part is monotone downward. This is why repeated quotienting along a path is a construction rather than an erosion — the path survives it, and gains.

Theorem 11.8 (a continuation that harms any node on the path is not forwarded). If each node forwards only on condition that its own value not decrease, then the component surviving a hop lies in the intersection of the alignments of every node so far, and a continuation lowering any one of their values has no hop that carries it. Such a packet is dropped, and by 11.2 nothing is held anywhere to reclaim.

Proof. Nonnegativity at each node is a conjunction over the path, and 11.4 keeps only what satisfies the node’s own conjunct. The intersection of the conjuncts is what survives all of them. Since the packet is the whole state of the thread (11.1) and no node retains any of it, a drop costs the network the packet and nothing further. ∎

Nonnegativity at each node is stronger than nonnegativity of the total: it holds over every subset of the path, so no segment of a surviving thread is a loss to its own members, and a thread cannot be made to pay for itself in the middle. So valid continuations are exactly the value-aligned ones, and alignment along a path is a property of the path, not a property any node checks on behalf of another.

Theorem 11.9 (the termination identity). Let the thread begin with n of source information. A productive hop drops at least one; a forward drops nothing. The thread terminates when the inherited part is exhausted, so the drops sum to n, and the number of productive hops is at most n.

Thread n = Σ[ ks ∈ List ℕ ] (Productive ks × (total ks ≡ n))

thread-length : (n : ℕ) (t : Thread n) → length (fst t) ≤ n

Proof. Each entry is at least one, so the length is at most the total, and the total is n. The box checks it. ∎

Remark 11.10 (the thread is a composition of n; the partition is its anonymisation). The drops in the order they were taken are a composition of n. Theorem 11.11 (the other termination: no peer interested and no peer holding). A thread also ends when, everywhere it can reach, no peer seeks the result and no peer holds a component of it. This termination is not 11.9’s: the inherited part may be untouched, so no drop has occurred and the bound of 11.9 says nothing about it.

Proof. Neither of 11.28’s two conditions is met anywhere reachable, so no node has a hop to make, so the thread has no continuation while its inherited part is whatever the last quotient left. ∎

A thread therefore has two ways to end — its information exhausted, or its audience exhausted — and only the first is bounded by the source (11.9). The second is bounded by the window (11.31), which is exactly what turns a thread that stopped into a proof that nobody held the result.

Definition 11.12 (the hop-budgeted packet). A packet may carry a program indexed by hops — accumulate at each of the next k peers, then return to the originator — so that the return is the hop at which the index reaches zero.

Its length is then a parameter rather than a consequence, and the two quantities of 11.9 come apart: such a thread may return with its inherited part unexhausted, and its drops sum to less than the source. By 5.16 with distance counted in peers, a budget below the number of hops to the furthest datum the program must read cannot complete, for every route and not for a chosen one. So k is bounded below by the construction and above by nothing.

Theorem 11.13 (a thread that loses nothing has no hop). A walk whose inherited part returns where it began has no productive hop at all. Persistence is therefore not a drop, and cannot be charged on either axis as loss.

Proof. zero-loss-no-hops in the box: a thread on 0 cannot begin with a positive drop, and a positive drop cannot sum to 0. ∎

Definition 11.14 (circuit, connection, bundle). A persistent cycle is a circuit; a persistent segment of a cycle is a connection. A circuit is a bundle of connections composing to a closed walk, and two bundles sharing a connection intersect. Bundles of circuits compose the same way, through their shared connections.

Theorem 11.15 (return is closure, and no reverse map is needed). The packet carries the originator’s request in its own history (11.1), so a node able to serve it forwards to the originator as an ordinary hop. Nothing travels back along the hops it came by, and no quotient is inverted. The round trip is the composite of the hop maps along the closed walk — an endomorphism of the originator’s state, and not the identity on it.

Proof. Each hop is a map forward by 11.4, and the composite of maps forward along a closed walk has the same source and target. It is not the identity unless every hop is a forward, by 11.7. That the originator is reachable is 10.19: its request is in the packet. ∎

So the cost of a return is the length of the cycle through the originator, which is a property of the graph and not twice the length of the thread. There is no privileged end of a thread; every node on the cycle is a node on the cycle.

Remark 11.16 (no node holds thread state). Because the packet carries the history, the code and the request, a node retains nothing of a packet it has forwarded — which is 10.20 read the other way: tail position only is the same statement as no node holding a frame. There is nothing to time out, nothing to reconcile, and nothing a node must be trusted to remember.

Theorem 11.17 (branching is copying, and the join is the one place order matters). Parallel execution copies the packet and distributes the copies, so a thread becomes a tree. The copy destroys nothing and costs only length (3.6). Two copies of one thread arriving at one node are the exception of 11.5: they share that node’s state, their hops do not commute, and the order becomes part of the result. That is the join, and what it costs is the identification the quotients destroyed — the shared prefix of the two histories.

Proof. Copying is a read, hence reversible, so by 3.5 it is free on the effect axis and by 10.19 its cost is the interval. For the join: two active pairs at one node share a cell, so 5.11’s disjointness fails and the diamond does not close them. What distinguishes the two copies is their histories, and by 11.6 their inherited parts have been quotiented along different paths, so nothing in the content identifies them as one source; the shared prefix of the histories is what remains. ∎

Each root-to-leaf path of the tree is its own composition (11.10) of the residual at the branch, so the total loss across a tree is not the source information — each path independently exhausts what it inherited. A join one hop below the branch is cheap to identify and has little to reconcile; a join at the leaves is the reverse.

Theorem 11.18 (a node is paid on its own closure, so a served node lies on a cycle). A node receives value when a continuation completes through it, and a continuation completes through a node only when the walk closes through that node. So every node a thread pays lies on a closed walk through itself, and a node on no such walk has no reason to forward.

Proof. Completion at a node is the arrival of a hop addressed to it, by 11.15; a walk that both leaves and arrives at a node is closed through it. ∎

Theorem 11.19 (a forward with no return is preferred whenever the peer will be met again). A node may forward with no return at all. Raising a peer’s capability raises that peer’s future-value (10.3), and by 10.9 that feeds back through the environment the forwarder also inhabits, on every later interaction with it. For information both loss terms of 10.10 are zero, so the condition reduces to whether later interaction is expected.

Proof. 10.9 applied with a cyclic resource of zero exclusivity: by 10.5 information carries no exclusivity of its own, so the direct loss is zero, and with nothing exclusive attached the indirect term of 10.10 is zero as well. What is left is the fed-back gain, which is realised on interaction with that peer. ∎

This is the alternative to a persistent circuit. Either every cycle persists, because every node on it requires its own return (11.23), or some nodes forward freely — and for information the free forward costs nothing on the effect axis and is preferred wherever the peer recurs. The construction permits both and forces neither. What it forbids is the forward that lowers the forwarder’s own value (11.8).

Theorem 11.20 (repetition must be kept, because the reduced object deletes the periphery’s closures). Allowing a walk to repeat nodes and edges, the two-step out-and-back on a single edge is a closed walk, so by 11.18 every node of a connected graph with an edge is payable. Cancelling adjacent inverse pairs sends exactly these walks to the identity, and the reduced object — free of rank m − n + 1 — records no closure through a node of degree one. The object the construction needs is therefore the walk monoid, with the reduced group as its quotient.

Proof. On a connected graph, reduction of closed walks at a base point gives a free group of rank m − n + 1, the number of edges outside a spanning tree. A degree-one node lies on no closed walk outside a spanning tree, so every closed walk through it reduces to the identity. By 11.18 that node is nonetheless payable, by the walk that reduction kills. So the quotient discards precisely the closures by which the periphery is served, and the unreduced monoid is the object that carries them. ∎

Theorem 11.21 (the two-node closures generate the whole space). Take the out-and-back walk on each edge together with one closed walk per independent cycle. Under product at the base point and insertion at any node a walk visits, these generate every closed walk of the graph. So the space is fixed by the topology and can be written down for any given one.

Proof. At a base point a closed walk is a word in the edges. Two words have the same reduction exactly when they differ by a finite sequence of insertions and deletions of adjacent inverse pairs, and each such pair is an out-and-back walk inserted at the node between them. Every reduced word is a product of the chosen basis walks, the free generators of 11.20. So any closed walk is a product of basis walks with out-and-back insertions, and conversely both operations produce closed walks. ∎

The two operations are what separates the monoid from its quotient: the product is visible in the reduced group, the insertion is not. By 11.20 the insertions are also what the periphery is served by, so neither operation is optional here.

Remark 11.22 (the fibre of reduction, on the smallest example). Take a five-cycle with one pendant edge: six nodes, six edges, rank 6 − 6 + 1 = 1, so the reduced group is ℤ. Joining the pendant’s two-step closure to the five-cycle gives a closed walk of seven steps, and there are four of these where a plain five-cycle has two. Reduction sends the four to two classes — a generator and its inverse — two walks to each. The first factor is the class; the second is fibre data the reduction discards, and it is where the pendant’s service lives.

Theorem 11.23 (a circuit is a fixed point of its composite, and so has no last node). A closed walk returning its inheritance intact is, by 11.13, all forwards. A circuit that persists therefore has each hop’s contribution supplying the next hop’s inherited part, and its composite carries the state to one from which the same walk is again admissible. A terminating thread is the inductive object, bounded in length by 11.9; a circuit is the coinductive one, and asking for its last node is asking for a hop whose completion comes from nothing.

Proof. If the inherited part strictly decreased on each hop of a closed walk, the composite would decrease it, contradicting return to the same state; and if it did not decrease, 11.13 makes every hop a forward. So persistence is replenishment: the contribution at each hop is the inheritance at the next. The composite then has the state as a fixed point by construction, and no node of the walk is distinguished, so none is last. ∎

This is why a circuit runs forever or not at all. It is also why the acknowledgement on a running circuit carries no content beyond the fact of one more unfolding: by 11.15 the round trip is no identity to compare against, and by 10.18 the closed part nets zero at every cut it does not cross. The heartbeat is the circuit, one step of it.

Theorem 11.24 (the acknowledgement is a position, and a dormant circuit resumes on the same connections). On a running circuit the acknowledgement carries one datum: how far along the thread the acknowledging peer has come — a position in that peer’s own order (10.22). By 11.23 there is nothing else for it to carry. A circuit in this state is live and unproductive, and at any unfolding a peer may send content instead, resuming productive interaction with no new circuit established.

Proof. By 11.23 a circuit’s only observable is its next unfolding, and by 10.22 what a counterparty needs of a party is its position in that party’s own order — so the unfolding carries exactly that and nothing is left over. A circuit is a persistent object (11.14), so the connections composing it are unchanged by the content of any one unfolding, and a content-bearing unfolding is the same hop as an empty one (11.4). ∎

So the heartbeat is not a convention added to keep a connection open. It is what 10.22 requires — freshness is a position, not a quantity — carried by the cheapest thing that can carry a position, which is one unfolding of a circuit that already exists.

Theorem 11.25 (a closed circuit needs no agreement outside itself). A circuit’s flow contributes zero at every cut it does not cross (10.18), so what requires visibility anywhere is only the part that has not closed. A circuit is private to the connections composing it, however long it runs, and only its open segment nets across a boundary. ∎

Definition 11.26 (the exchange). One party holds f : B → C and seeks an inhabitant of C; another holds b : B. Neither side’s deliverable is constructible alone and each is constructible given the other’s. The return is the application.

Theorem 11.27 (the exchange leaves both parties holding C, and nothing moved). After the exchange of 11.26 the party that held f holds a C and the party that held b holds a C. Nothing was transferred: the b that was sent is still held and the f that applied it is still held (3.6). The exchange is a duplication whose two outputs agree, and its only cost is the transport.

Proof. f b is constructible at either node once both are present there, and sending b leaves it where it was, by 3.6. So both nodes hold an inhabitant of C, and these agree because both are f b. By 10.8 the cost is the interval occupied by the transport and nothing on the effect axis. ∎

This is what it means for both to end with a construction of C, and it is why the exchange needs no scalar (11.28) and no balance (10.11): neither side gives anything up. The balance of §10 is for the case this one excludes — where what is exchanged is exclusive, and by 10.5 that is the only case where it is needed.

Theorem 11.28 (the exchange fixes whom to forward to, with no scalar). A node forwards to a peer that either seeks the result sought or holds a component of it. In the second case the forwarder obtains a C it could not have constructed, which by 10.3 raises its own future-value. Nothing numeric passes, and no network-wide quantity is required to exist — by 10.21 there is none.

Proof. The two cases are the two ways the hop can be value-aligned for the forwarder under 11.4: the result is sought downstream, so forwarding advances a continuation that completes through this node (11.18); or it is held downstream, so the hop returns an inhabitant of C here. ∎

Corollary 11.29 (an exchange whose answer depends on its input cannot be anonymised). A party receiving only the truncation of B receives the one point, and by 8.5 the which-inhabitant pre-image has been discarded. So an f taking different values on two inhabitants of B is not computable from the truncation, and the party must receive b itself.

Proof. A map out of the truncation assigns one value to the whole of B, since any two points of the truncation are equal. If f b ≠ f b′ it admits no such factoring. ∎

Definition 11.30 (the window). For a finite set of peers, let T be a length such that every pair is mutually reachable at least once within every window of that length. Any subset of the pairs may then have interacted within one window, so T is a period of the whole network and not of one edge.

Theorem 11.31 (the window makes absence provable). With the peers finite and T as above, a search that fails across one window of length T is a proof of absence rather than a search that has not returned.

Proof. The pairs are finitely many and each was reachable within the window, so failure across the window is failure at every peer, which is a finite conjunction of negations. Without T no such conjunction is ever complete, and absence is only the absence of an answer — the Σ is undecided rather than refuted (8.4). ∎

So T is what makes a negative answer a thing a node can hold and forward. It also bounds the quantity 10.15 requires fresh — nothing older than a window need be carried — and bounds how long an open cycle can stay invisible before a cut crosses it (10.18).

Remark 11.32 (the dual presentation). n peers forwarding one packet, and n controllers over one shared memory each updating it and passing control to a chosen next, are the same object read two ways: the packet is the memory and the forward is the transfer of control. Nothing in §§10–11 distinguishes them — the hop is a rewrite on a pair either way (11.5) — so none of it is committed to message-passing, and the construction reads the same whether the information moves between holders or the control moves across one holding.

Remark 11.33 (what is not derived). The hop maps are each node’s own. Nothing above makes them agree, and alignment along a path is not assumed transitive. That a peer is reachable, that it forwards at all, and that it acts on its own stated value are not derived — relations between peers are taken as ephemeral, and no node serves anything beyond its own intentions. What is derived is only what follows once a hop keeps what it keeps: that the drops sum to the source and the hops are bounded by it (11.9), that a closure losing nothing is unproductive (11.13), that return is composition and not reversal (11.15), that no node holds thread state (11.16), that a circuit is a fixed point with no last node (11.23), and that the periphery is served only by the closures the reduced object discards (11.20). Not derived: that a peer will be met again, which 11.19 requires as an expectation and supplies no ground for; that a hop budget (11.12) is set well; and that the window of 11.30 exists for a given set of peers, which is an assumption about them and the one thing 11.31 cannot do without.
