Respecting Equality: Complete Inference, Deterministic and Step-Optimal

Avik Jain

This is one construction on how equality behaves in cubical type theory: equality of types is equivalence — Voevodsky's univalence — and it computes. No prior familiarity with either is assumed.

From that one fact the construction builds to a single result: complete inference — proving, computing, deciding, or answering any well-formed question — runs deterministically and in the fewest possible steps: a count fixed by where the reduction starts and ends, never by which strategy walks between them. The exact form of the Gödel and Turing limits is a stop on the way (§4). The natural numbers, and the complex numbers with the field equations, are two readings of the finished construction, set out after it. The shape is worth knowing in advance: §§0–2 are one chain, each step from the one before, ending in univalence; §3 and §4 are two facts that chain does not give, each standing on its own; §5 is where all four are used. Every step is elementary, and at each one the computational core is machine-checked and runs — the boxed terms below, verbatim and checkable as printed.

0. The one fact

  • A type is a collection of values (a : A); a function f : A → B maps values to values. A pair type Σ (a : A) (P a) holds pairs (a , w) where the type of the second part, P a, may depend on the first — P a family, one type P a for each a.
  • Equality is a type: x = y is the type of proofs that x equals y; refl : x = x. A proof is a value you keep.
  • The interval. A proof of equality is a path, and a path is a map out of the interval 𝕀 — which is not assumed but built: the free De Morgan algebra on one generator — a bounded distributive lattice, endpoints 0, 1, carrying meet ∧, join ∨, and an order-reversing involution ~ that exchanges the endpoints (~0 = 1). Two of those are used directly below: ∧ builds the contraction in the Fact (the i ∧ j in its checked term), and ~ reverses a path. ∨ earns its place with the filling of §2, where a square is closed from two of its sides. A path x = y is a map 𝕀 → A with 0 ↦ x, 1 ↦ y; refl is the constant map. Everything below — transport, J (the slide, built with ∧), function extensionality, univalence (§2) — is built from this interval and one thing done with it: paths along it compose, and can be pushed along one another (the filling of §2), which each type former supplies for its own type rather than having it assumed. So the base is the interval and its operations, and no axiom is added about any type.
  • Contractible = some point exists, and every element is equal to it — so the whole type collapses onto that one point.
  • Substitution (transport). A proof p : x = y lets you carry any structure from x to y: for any family P it gives transport p : P x → P y, run backwards by transporting along the reversed path λ i → p (~ i), and transport refl = id (moving nowhere changes nothing) — a reversible, lossless program.
  • Fact: Σ (y : A) (x = y) — the values y : A equal to x, each with its proof — is contractible, centre (x , refl). The path from the centre to any (y, p) is built by sliding along p itself: at stage t sit at the point p t, holding as its proof the piece of p from x up to t (so you have shown x = p t); at t = 0 that is (x , refl), at t = 1 it is (y, p). One point, everything equal to it.
  • Path induction (J). To act on every (y, p : x = y) it therefore suffices to give the value at (x , refl) and transport it forward to (y, p) along the contraction path. This is the eliminator of = (its J: to prove something about all equal pairs, prove it at the centre) — and transport is exactly J for a goal C(y, p) that ignores the proof p (C(y, p) = P y), so the two are one thing. (The identity type's eliminator is its initiality as an inductive family — Awodey–Gambino–Sojakova 2012.)
  • §1 is this fact with x replaced by a function's output.

1. Partition by output

  • Take f : A → B. Write f⁻¹(b) for the inputs over b — the inputs that land on b, each kept with its proof that it does: f⁻¹(b) = Σ (a) (f a = b).
  • Then A matches its inputs grouped by output, losslessly — write ≅ for such a lossless match (maps both ways that cancel; defined in §2): A ≅ Σ (b : B) f⁻¹(b), by a ↦ (f a, (a, refl)) with inverse (b, (a, p)) ↦ a. Both round trips are refl (the return uses the kept proof p : f a = b): nothing is lost, only regrouped.
  • And this grouping is the only lossless one. This is the one place §1 leans forward: the partition above needs nothing after it, while the uniqueness below uses §2 twice, for univalence and for function extensionality. Call any other a completion: a family T assigning a type T(b) to each b, that reassembles A the same way — a match A ≅ Σ (b) T(b) that respects the output map (an input's b is unchanged). Respecting it means the match leaves an input's b alone, so it carries the piece over each b to the piece over that same b — and the inputs over b on the right-hand side are exactly T(b), so the match carries f⁻¹(b) onto T(b). A completion is thus a choice, at each b, of a type matching f⁻¹(b) — and the types matching a fixed one collapse to a single point (univalence, §2: Σ (X) (X ≅ Y) is contractible). A per-b choice among one-point options is again one point (functions that agree at every argument are equal — function extensionality, itself from §2). So T can only be the family f⁻¹: the decomposition is forced, not a chosen encoding.
  • Every decomposition below is this: group by output, keep the inputs over each b.

2. Isomorphism is substitution

  • A ≅ B (isomorphism, the lossless match promised in §1): maps both ways with proofs they cancel — runnable in both directions, nothing lost either way. The displays and the checked terms write it ≃, the same thing.
  • The same thing can be said piece by piece: f⁻¹(b) is contractible for every b (§0) — an inverse g centers it at (g b, ·), and the cancellation laws contract every (a, p : f a = b) onto that center; conversely, choosing the center of each f⁻¹(b) is an inverse. So a two-sided inverse and every f⁻¹(b) contractible imply each other. They are not the same type: being contractible-fibred is a property, true in at most one way, while an inverse is data that may be given differently — which is why the second is the one carried around.
  • Univalence — a theorem, not an axiom. The primitive is the interval: a path x = y is a map out of it, and §0's contraction is one such map (the i, the i ∧ j in its checked term are the interval's own structure); paths can be joined end-to-end and pushed along one another (Kan composition — this is what runs transport). From an equivalence A ≅ B, a Glue type builds a type that equals A at one end and B at the other — a path A = B whose transport is exactly that equivalence. So A ≅ B ⇒ A = B, and it computes: transport^{ua e} = e. Hence the space of types equivalent to a fixed one is contractible: it is §0's fact read at the universe, with = between types supplied by ua. That is the fact §1 used. And isomorphic structures interchange by a program, losslessly. Voevodsky's axiom is here built from the interval and Glue (Cohen–Coquand–Huber–Mörtberg 2018).
$$ (A \simeq B)\ \simeq\ (A = B), \qquad \mathsf{ua} : (A \simeq B) \longrightarrow (A = B), \qquad \mathrm{transport}^{\,\mathsf{ua}(e)} \;=\; e $$

3. A step is reversible when its input can be recovered

  • A step is reversible when you can recover its input from its output — it runs backward as well as forward, losing nothing (§2). transport and every isomorphism are of this kind.
  • A step is irreversible when several inputs share one output b: then which of them the input was is gone. That forgotten "which one" is the only thing a step can ever destroy. Call its size the step's effect-cost — what the step costs in information, as against how many steps are taken, which §5 calls length. The effect-cost is the entropy of the input given the output: log₂ of the number of inputs mapping to b when those are equally likely (2ᵏ inputs → k bits), and less when they are not — the count is the most it can be.
  • Landauer's principle prices it: destroying k bits dissipates at least k · k_B T ln 2 of heat (k_B Boltzmann's constant, T the temperature). So information destroyed and heat dissipated are the same quantity — the forgotten input — and a step you can run backward forgets nothing, so destroys and dissipates nothing. That last part — reversible costs nothing — is not special to counting bits. Any additive measure of destruction vanishes on the reversible steps, because each has an inverse and a sum of naturals is 0 only when each summand is — and that is all it takes, no associativity or other group law:
$$ \ell(g) + \ell(g^{-1}) = \ell(\mathrm{id}) = 0 \;\Longrightarrow\; \ell(g) = 0 \qquad (\text{naturals} \ge 0) $$
  • So transport and every isomorphism destroy nothing — every construction in §§1–2 runs backward and dissipates no heat. The only thing a computation ever loses is an input it chose to forget; how many steps it takes to reach the answer is a separate matter (§5).

4. The diagonal

  • Picture e : A → (A → B) as a table whose row a is the function e a; reading row a at its own index gives e a a (the diagonal). Say e is onto when every function h : A → B appears as some row: given h, a row index a with e a = h is produced, not merely said to exist — which is why the Σ below and in the box is the untruncated one, and why the fixed point comes out as a value you can hold.
  • Then every g : B → B has a fixed point:
$$ \Big(\forall\, h : A \to B.\ \ \Sigma\, a : A.\ \ e\,a = h\Big) \;\Longrightarrow\; \Big(\forall\, g : B \to B.\ \ \Sigma\, b : B.\ \ g\,b = b\Big) $$
  • h a := g(e a a); e onto gives h = e a₀; so:
$$ e(a_0)(a_0) \;=\; h(a_0) \;=\; g\big(e(a_0)(a_0)\big) $$
  • e a₀ a₀ is a fixed point of g.
  • Contrapositive: g with no fixed point ⇒ no A → (A → B) is onto.
  • Cantor. B = 2, g = ¬: negation swaps true and false, so it has no fixed point, and (A → 2) is the decidable subsets of A by characteristic functions (not every subset: that would be maps into propositions) — so no A → (A → 2) is onto, which is Cantor's theorem.
  • Gödel. Code each one-variable formula by a number, and let sub(m, n) be the code of formula m with the numeral n̄ substituted for its variable. One fact does all the work, and it is built, not assumed: sub is primitive recursive, and every primitive-recursive function is represented by a formula — induct on how it is built, the base functions (zero, successor, projection) are formulas, and composition and primitive recursion stay first-order by quantifying, boundedly, over the finite run that computes the value. So sub is itself a formula.
    Now §4 applies on the nose, with the table e(m)(n) = sub(m, n): row m is the formula coded by m, and reading row m at its own index is sub(m, m). Point-surjectivity — every family of formulas that is itself cut out by a formula occurs as some row sub(m, ·) — is that representability, nothing more. So lawvere fires: for g = ψ its twist δ(x) := ψ(sub(x, x)) is a formula, has a code d, and the fixed point G := δ(d̄) has code sub(d, d), so G ↔ ψ(⌜G⌝). That is the diagonal lemma — lawvere itself at φ = sub, g = ψ, fixed point G. The B it fires over is the sentences taken up to provable equivalence, where ↔ is equality; g b = b read there is exactly G ↔ ψ(⌜G⌝). So this is the theorem applied at a named (B, g), not an analogy to it.
    Take ψ = ¬Prov, with Prov(⌜G⌝) the formula a proof of G exists — one unbounded existential over a decidable check of the proof, which is what Σ₁ names: then G ↔ ¬Prov(⌜G⌝) says I am unprovable, so if the theory is consistent no proof of G exists and G is therefore true. Incompleteness is the one diagonal at g = ¬ over provability — the self-reference is just sub applied to its own code.
  • Halting. B = 2, and the decider is what would supply the point-surjection. Running code a on input x is partial, so it is no table of total functions; a total halting-decider H makes it one, since φ(a)(x) := if H(a,x) then run(a,x) else 0 is then total. And every total computable h : A → 2 is a row of it — take any program for h; it halts everywhere, so H never diverts it. That is point-surjectivity. Now §4 at g = ¬: the twist δ(a) := ¬φ(a)(a) is total and computable, so δ = φ(d) for some code d, and reading row d at its own index gives φ(d)(d) = ¬φ(d)(d) — which ¬, having no fixed point, forbids. So no total H exists: nothing decides, of an arbitrary machine and input, whether it halts.

One lemma; the impossibility theorems are its instances, each built by naming its fixed-point-free (B, g). Russell: B the propositions, g = ¬ on x ∈ x — the non-self-members are the diagonal row, and ¬ fixes nothing, so they are no set's membership. Tarski: B the truth values, g = ¬ — a truth predicate would make the liar a fixed point of negation. The positive reading is the same implication where g does have fixed points: where e has a section (an interpreter), the lemma hands every g one — a program equal to its own transform, which is Kleene's recursion theorem, the quine. Rice sits on that side rather than among the fixed-point-free instances: suppose a decider for a nontrivial semantic property, and take programs a that has it and b that lacks it. The recursion theorem builds a program which reads its own code, runs the decider on it, and then behaves like b if the verdict is yes and like a if no — so either verdict is wrong about it, and no such decider exists. There is no family of impossibility theorems: one lemma, applied at a different (B, g) each time, and read in the other direction for the recursion theorem. (Lawvere 1969.)

PtSurj : (A → (A → B)) → Type
PtSurj {A = A} {B = B} φ = (g : A → B) → Σ[ a ∈ A ] φ a ≡ g

-- Read the row at its own index, then apply f.
twist : (A → (A → B)) → (B → B) → (A → B)
twist φ f a = f (φ a a)

-- Lawvere 1969: a point-surjective φ forces every endomap of B a fixed point.
lawvere : (φ : A → (A → B)) → PtSurj φ → (f : B → B) → Σ[ b ∈ B ] f b ≡ b
lawvere φ surj f = φ a₀ a₀ , sym (funExt⁻ (surj (twist φ f) .snd) a₀)
  where a₀ = surj (twist φ f) .fst

-- Contrapositive: one fixed-point-free f kills point-surjectivity of every φ.
noFix→noPtSurj : (φ : A → (A → B)) (f : B → B)
  → ((b : B) → ¬ (f b ≡ b)) → ¬ PtSurj φ
noFix→noPtSurj φ f nofix surj = nofix (lawvere φ surj f .fst) (lawvere φ surj f .snd)

-- not has no fixed point: not true = false and not false = true.
not-no-fix : (b : Bool) → ¬ (not b ≡ b)
not-no-fix true  p = true≢false (sym p)
not-no-fix false p = true≢false p

-- Cantor, as the B = Bool, f = not instance (not has no fixed point).
cantor : (φ : A → (A → Bool)) → ¬ PtSurj φ

5. Complete inference is deterministic and step-optimal

§§0–2 supply substitution along an equality, §3 reversibility, §4 the diagonal. This section fixes a machine, defines two costs on it, and proves the result stated at the top.

5.1 Terms, proofs, questions

Definition 5.1 (the correspondence). Each connective is read as a type former:

A ⇒ BA → B, the function type: a proof sends a proof of A to one of B
A ∧ BA × B, the pair
A ∨ BA ⊎ B, the tagged sum
falsehood⊥, the empty type
∀ x. P x(x : A) → P x, the dependent function
∃ x. P xΣ[ x ∈ A ] P x, the dependent pair
modus ponensapplication
checking a proofnormalizing its term: running it until no step is left

With sums and the empty type in the list, the connectives and the type formers are one structure: the free bicartesian closed category (Curry 1934; Howard 1969; Lambek 1980).

Definition 5.2 (question, answer). A computation is a term of a value type, a decision a term of Dec P = P ⊎ ¬ P, an answer a term of the type the question asks for. The answer to a question is the normal form of that term.

Proposition 5.3. Proving, deciding, computing and answering are one operation: build the term, normalize it.

Proof. Immediate from 5.1 and 5.2 — the four differ only in which type the term inhabits. ∎

5.2 The machine

Definition 5.4 (net). A cell has one distinguished principal port and finitely many auxiliary ports. A net is a finite set of cells with a partial matching of their ports by wires. The distance between two cells is the number of wires on a shortest path between them.

Definition 5.5 (interaction step). An active pair is two cells whose principal ports are wired to each other. For each pair of cell kinds a rule gives a net R on exactly the auxiliary wires of those two cells:

$$ \dfrac{\;(c_1,c_2)\ \text{an active pair of}\ N \qquad (c_1,c_2) \longrightarrow R\;}{\;N \longrightarrow N[(c_1,c_2) := R]\;} $$

Every other cell and wire of N is unchanged. Write Step s t for one such step.

Definition 5.6 (trace, length, normal form).

data Trace : ℕ → S → S → Type where
  done      : {s : S} → Trace zero s s
  stepTrace : {n : ℕ} {s u t : S} → Step s u → Trace n u t → Trace (suc n) s t

Normal : S → Type
Normal t = (u : S) → Step t u → ⊥

The length of a trace is its index n.

5.3 Two costs

Definition 5.7 (the two axes). The length of a reduction is the number of steps it takes (5.6). Its effect-cost is the quantity §3 defines: the entropy of its input given its output.

Proposition 5.8. A reversible step has effect-cost 0 and length 1. A step merging 2ᵏ inputs into one output has effect-cost k and length 1.

Proof. A step whose input can be recovered is a bijection (§3), so one input shares each output and log₂ 1 = 0; a 2ᵏ-fold merge gives log₂ 2ᵏ = k. Neither reading touches the step count. ∎

Proposition 5.9 (Landauer's bound, in units). A step of effect-cost k dissipates k · k_B T ln 2 of heat, and a reversible step dissipates 0.

Proof. §3 read twice — once on the datum, once on the dynamics carrying it. A 2 → 1 merge of microstates is an entropy drop of ln 2 nats, k_B ln 2 once k_B converts nats to thermodynamic entropy. §3 splits the ambient dynamics into two cases. Injective: the two microstates the step merged stay distinct in it, so the distinction the datum lost is now in the surroundings, as heat T ΔS, with T the conversion of entropy to energy that defines temperature. Non-injective: it is a merging step itself, and §3 charges it the same k one level down. Both cases pay k bits; k_B and T convert that to joules. By 5.8 a reversible step has k = 0, so the drop is 0 and the heat is 0. ∎ (Landauer 1961; Bennett 1973, 1982 named it.)

Remark 5.10. The price is relative to the observation: it is the bits erased for the requested output, not for a whole trace. The length cost is a separate axis, bounded by a potential (5.15) and by no count of solutions (Search).

5.4 Every reduction is the shortest

Lemma 5.11 (one-step diamond). If Step s a and Step s b then a ≡ b, or there is c with Step a c and Step b c.

Proof. Two distinct active pairs are disjoint: distinct principal-port pairs cannot share a cell. By 5.5 each step leaves everything outside its own pair untouched, so doing one leaves the other available and untouched, and the two converge in one further step each. This is structural to interaction nets (Lafont 1990), not an assumption. ∎

Lemma 5.12 (peel). Step s u → Trace (suc n) s t → Normal t → Trace n u t.

Proof. Induction on the trace's length. Apply 5.11 to the given step and the trace's first step: either they merge, and the tail is the required trace, or they reach a common term, from which the inductive hypothesis peels the shorter tail. At a normal form no step is left to carry, so the given step is absorbed exactly once. ∎

Theorem 5.13 (equal length). Trace n s t → Trace m s t → Normal t → n ≡ m.

Proof. Induction on the first trace, peeling its first step through the second by 5.12. ∎

Corollary 5.14. Every reduction of a term to its normal form has the same length, so each is the minimum: the step-count is fixed by the endpoints, never by the strategy, and the cost is as deterministic as the answer.

Proof. 5.13 with ≤-refl, as normalization-is-geodesic in the box. ∎

Theorem 5.15 (Bellman). In the reduction graph — vertices terms, edges steps of cost c(u→v) — call Φ a potential when Φ(normal form) = 0 and Φ(u) ≤ c(u→v) + Φ(v) on every edge. Then every potential is a lower bound on every finishing path, and where a normal form is reachable the geodesic distance is the greatest potential, satisfying

$$ \Phi(\text{normal form}) = 0, \qquad \Phi(u) = \min_{v}\, \big[\, c(u \to v) + \Phi(v)\,\big] $$

Proof. Adding the edge inequality along any path to a normal form, where Φ = 0, gives Φ(u) ≤ the path's total cost. The geodesic distance satisfies both conditions, so it is a potential, and it meets the bound with equality at the cheapest edge (Bellman 1957). By 5.14 it is attained by every reduction, so there is nothing to minimise over. ∎

Theorem 5.16 (unit lookahead). An output that must read input at distance n from it cannot be produced in fewer than n steps — a bound on every reduction, not on one chosen strategy.

Proof. By 5.5 one step changes the datum only where its two cells sat, so its output at a position depends on that position and its one wired neighbour. Composing k steps, the output depends only on input within distance k of it in the net one started from: one step reaches a wired neighbour, so each widens the reach by exactly one. The rewriting does not let that slip — a rule replaces two cells by a net on their own auxiliary wires, and the cells it puts there can carry only what those two already held, so no interaction moves information further than one wire, however the distances in the rewritten net come out. ∎

Corollary 5.17 (step-optimality). The native evolution attains the geodesic: no reduction is shorter than the one it takes.

Proof. 5.14. ∎

Theorem 5.18 (unique normal form). A term has at most one normal form.

Proof. 5.11, tiled. Take two reductions of one term; the diamond closes their first steps to a common term, and filling the grid step by step reconverges them. If both end at a normal form — nothing left to rewrite — that common reduct can only be each endpoint, so the two are equal. (Church–Rosser, here the diamond filled in.) ∎

Corollary 5.19 (the dichotomy). For every question there are two cases and no third. Either a normal form exists, and by 5.14 and 5.18 every reduction reaches that one answer in the one step-count the endpoints fix; or §4 proves there is none — a decider for one's own halting is among these, since asking for one asks for the fixed point the diagonal forbids — and the question had no answer to find, which the system establishes rather than running out of time looking.

Remark 5.20. Well-formed names the first case, and the reduction decides which case a question is in. What 5.19 fixes is reachability, not length: a long geodesic is a real price, charged honestly, and by 5.14 it is already the minimum.

5.5 What the length counts

Proposition 5.21 (the building route is the size of the answer). The normal form is a complete proof-carrying witness — the answer with its certificate — and the steps that build it number exactly its constructors.

Proof. Each building step emits exactly one constructor — one piece of the answer, a successor, a pair, a tag — so the building route's length equals the witness's size; building sucⁿ takes one successor per step. A term carrying extra redexes — spots still waiting to reduce, like (λx.x) t — clears those first, administrative steps building nothing, so its total length is its own geodesic by 5.14 while the witness's size counts only the constructors built. Reading the finished term off is a fold that copies it, adding no step. ∎

Remark 5.22 (two exponentials). By 5.21 the building route's length is the witness's size in unary. When that unary size is exponential in the question's succinct binary measure — as sucⁿ is, n against log n — the route is exponentially longer than the succinct measure. That exponential is the observer's lossy binary measure laid against a lossless unary object; change the measure, not the computation, and it is gone. The other exponential can be real: the geodesic length when a small witness ends a long reduction. That is a length, so no change of measure touches it; it is the reduction's own fixed distance, already the minimum by 5.14.

Remark 5.23 (what is solved). The optimization problem — the fewest steps to an answer, what complexity theory exists to chase — is here solved: computation modeled as lossless reduction is optimal by construction, optimality its standing condition. The million wasteful ways to compute the same answer are departures from this model, not rival strategies within it. Only 5.11 is used, so 5.13–5.19 hold of any reduction that has the diamond.

Remark 5.24 (sharing). Sharing is written into the net. A shared subterm is held by a cell — a duplicator, wired in at ports like every other cell — so it belongs to the net's syntax, in place before any reduction begins: no bookkeeping outside the net itself, and 5.11 used only the disjointness of active pairs, not sharing. Its price is charged: a duplicator's interactions are steps on the length axis exactly like the rest, and on the effect axis they are free by 5.8, since folding along an equality is transport (§2) and runs backward (§3). What sharing buys is the one thing claimed for it: an active pair is never duplicated, so no step repeats work.

Remark 5.25 (termination). Where a term terminates it is reached in finitely many forced steps; a non-terminating term denotes a well-defined infinite (coinductive) object, not a gap.

Remark 5.26 (no outer layer). Evaluator, type-checker and optimizer are themselves terms of the same language, and a question about them is another term the same normalizer reduces. There is no meta-level, so no self-reference contradiction: reasoning about its own terms as data, it proves the §4 impossibilities as ordinary theorems — and, as those theorems say, it does not decide its own halting, and has a sentence it neither proves nor refutes. Any expressible system, this one included, is lawful construction and identity, operated on exactly as everything else is: the language is its own metatheory, standing nowhere outside itself.

Numbers

  • To count a finite set is to forget which element is which. Any two n-element sets differ only by a relabelling (a renaming of elements), so all of them are one thing. What the forgetting throws away is exactly the relabellings — the n! permutations of n things, the group Sₙ. To count is to keep the class and discard Sₙ:
$$ \mathbb{N} \;=\; \{\text{finite sets}\}\,/\,\cong, \qquad \mathrm{Aut}(\text{an } n\text{-element set}) \;=\; S_n $$
  • So card is the bijection between iso-classes of finite sets and ℕ, with inverse n ↦ {1,…,n}.
  • Addition = disjoint union (|A ⊎ B| = |A| + |B|), multiplication = product (|A × B| = |A|·|B|). Written in base b, adding two digit strings is this disjoint union done place by place, carrying whatever overflows a place into the next.
  • Divisibility orders ℕ: d ∣ n iff each prime's exponent in d is ≤ its exponent in n. So gcd = meet (min exponents), lcm = join (max); and unique factorization sends n to its exponent vector, making ℕ the product of one chain (ℕ) per prime — where min and max distribute componentwise, a distributive lattice.
  • That is the same distributive lattice as the algebra of logic (Search): gcd/lcm ↔ ∧/∨, coprime ↔ disjoint, and CRT ℤ/mn ≅ ℤ/m × ℤ/n — by x ↦ (x mod m, x mod n), injective since coprime m, n both dividing x−y force mn ∣ (x−y), hence bijective by count — matching the product decomposition, with the order-reversing involution d ↦ n/d giving De Morgan on both. Being finite and distributive, the divisor lattice is a Heyting algebra for every n; what varies is whether that involution is the Heyting negation. On squarefree n it is — a divisor is a subset of the primes and n/d its complement — so the lattice is Boolean. A repeated prime breaks it: on n = p² the divisors are the chain 1 < p < p², where the Heyting negation of p is 1 and ¬¬p = p² ≠ p, while the involution sends p to n/p = p. So number theory and logic are one and the same logic — gcd and lcm the conjunction and disjunction, the divisibility order entailment — Boolean exactly where n is squarefree, and properly intuitionistic otherwise.

Complex numbers and quantum dynamics — the reversible side of §3

  • σ(x, y) = (-y, x) — a length-preserving quarter-turn of the plane. Write i for σ: then σ(x,y) = (−y, x) is i·(x + iy) = −y + ix. It is reversible — lossless, and free on §3's effect axis.
  • σ²(x,y) = σ(−y,x) = (−x,−y) = −(x,y), so σ² = −1: σ is a square root of −1, its powers cycling 1, σ, −1, −σ — the four phases {1, i, -1, -i}. The identity σ² = −1 needs no analysis and holds over any ring — the box checks it on the integer lattice, where it is exact arithmetic — and adjoining σ to the reals by those same two lines is ℝ[σ]/(σ²+1) = ℂ. σ, a rotation, preserves length — it is unitary. So the complex numbers, the phases, and unitarity are generated by this one reversible operation. Unitary evolution is exactly §3's free, reversible side; the physics that costs — measurement, erasure — is the irreversible side (Landauer, §5).

At a = b = F that makes ⟨F, ∇×F⟩ real, so its imaginary part vanishes. The generator −i∇× is therefore skew-adjoint: the flow preserves length, i.e. is unitary.

$$ \text{solutions of } F \;=\; F^{-1}(\text{true}) \;=\; \{\, w : F(w) = \text{true} \,\}, \qquad \#\text{solutions} = \sum_{T \subseteq C} (-1)^{|T|}\, 2^{\,N - r(T)} $$
  • F : assignments → {true, false}. Solutions S_F = F⁻¹(true). For 3-SAT a clause forbids exactly one setting of its 3 literals, so the assignments that break it fill a subcube V_α — those 3 bits fixed to the forbidden setting, the other N−3 free (a codimension-3 face); every assignment either satisfies all clauses (in S_F) or lies in some V_α, and S_F is disjoint from ⋃ V_α, so the whole cube splits, Q_N = S_F ⊎ ⋃ V_α with Q_N the 2^N assignments — deciding and solving are two observations of one partition. Count by inclusion–exclusion: #S_F = Σ_{T⊆C} (−1)^{|T|} |⋂_{α∈T} V_α|. When the clauses in T can be violated together, |⋂_{α∈T} V_α| = 2^{N−r(T)} with r(T) the coordinates they jointly fix; when two of them demand opposite values on a shared variable the intersection is empty and contributes 0. Regroup the sum per assignment by the j clauses it breaks: its weight is Σ_{i≤j} C(j,i)(−1)^i = (1−1)^j, which is 1 only at j = 0 — each solution survives once, the rest cancel.
  • Deciding = ‖S_F‖, writing ‖·‖ for the proposition this is inhabited — one bit, and when true it is a single point, every witness collapsed onto it. Solving = S_F (a vertex with its membership proof). The truncation τ : S_F → ‖S_F‖ sends every witness to that one point, so its pre-image is all of S_F: that pre-image is Σ (w : S_F) (τ w = pt), and ‖S_F‖ has any two of its points equal, so the equality component carries nothing and the pre-image is S_F itself — the one-bit decision discards exactly the which-witness pre-image, with no left inverse once |S_F| > 1.
  • Decide = verify. For the machine's step f, deciding an input a completes it to (answer, witness) — by §1 that completion is the equivalence A ≅ Σ (b) f⁻¹(b), here decide(a) = (f a, (a, refl)): the answer, paired with the input and the refl proof it maps there. verify reads the witness's pre-image back out; the round trip is refl. Deciding and verifying are thus the two directions of that one equivalence, unique by §1 — the decided witness carries its own acceptance as refl, so nothing is searched between having the answer and having its certificate: the lossless run produces the witness with the answer — one forward pass, no second search — and verifying is that pass reversed. The one-bit decision ‖S_F‖ above is the lossy projection that throws the witness away (τ); the lossless machine never does. So on the lossless machine there is no operation sitting between deciding and verifying for a gap to live in: they are one equivalence read two ways. What is left to ask of a problem is how many steps the output it asks for forces, and §5 fixed the form any answer to that must take — a lower bound on the step count is a Φ that is 0 at the normal form and, along every primitive step, exceeds the next Φ by at most that step's cost. The last bullet below is about which quantities meet that condition and which do not.

UNSAT iff it is 0; an unsatisfiable formula whose every clause has exactly 3 literals needs m ≥ 8 of them — writing ν(x) for the clauses assignment x violates, each clause is violated by 2^{N−3} assignments and UNSAT means every x violates at least one, so Σ_x ν(x) = m·2^{N−3} ≥ 2^N, i.e. m ≥ 8 — and sharp, since the eight clauses on three variables, one for each sign pattern, forbid all eight settings and so are unsatisfiable with exactly eight.
  • These counts are not such a Φ. Four counts get proposed as lower bounds — assignments, satisfying vertices, clause-intersections, and the width of a fixed-order pass (the number of distinct states a left-to-right reading has to keep). Each collapses under factoring or a change of coordinates (disjoint triples: m clauses on disjoint variable-triples each kill 1 of 8 and leave 7, so #SAT = 7^m while the intersections number 2^m; inner-product ⟨x,y⟩ mod 2: read all of x first and the state reached must fix the map y ↦ ⟨x,y⟩ — distinct x ≠ x′ give different maps, disagreeing at y = e_i, the vector with a single 1 in place i, wherever x_i ≠ x′_i, so the 2ⁿ inputs force 2ⁿ distinct states, width 2ⁿ; read the pairs x_i, y_i interleaved and it is a running parity — remember x_i (2), fold x_i y_i in (2) — width ≤ 4). A lower bound is a Φ with Φ(normal form) = 0 and Φ(u) ≤ c(u→v)+Φ(v) on every primitive edge, in §5's notation; distance is the greatest such Φ. With unit-cost primitive steps the defining inequality reads Φ(u) ≤ 1 + Φ(v), so Φ can fall by at most one per step; an exponential lower bound is therefore a Φ that starts out exponential and still falls by at most one per step — equivalently, an exponentially large supply of obligations of which one step can discharge at most one. That is what such a proof has to exhibit. Nothing here exhibits one for SAT.
